# SET-007 — KIND RETIRED GENTLEMAN

ชื่อแนวคิด: **ผู้ใหญ่ใจดี เกษียณแล้วก็ยังเท่**

ชุดนี้เป็น LINE Sticker จำนวน 40 แบบ สำหรับการสนทนาแบบสุภาพ อบอุ่น เป็นกันเอง และใช้งานได้จริงในชีวิตประจำวัน

## Core Direction
- ผู้ชายวัยผู้ใหญ่ใกล้/หลังเกษียณที่ยังดูดี แข็งแรง กระฉับกระเฉง และมีเสน่ห์
- ไม่ใช้เครื่องแบบตำรวจเป็นลุคหลัก
- ชุดหลักเป็นแจ็กเก็ต/ชุดวอร์มสีเทาแนวสปอร์ตตามภาพอ้างอิง
- รักษาความคล้ายต้นแบบในระดับที่จดจำได้ แต่ stylize ให้เหมาะกับ LINE Sticker
- ห้ามทำให้ดูแก่ โทรม อ่อนแรง หรือ caricature เกินจริง

## SSOT
เอกสารที่ใช้เป็น SSOT อยู่ใน `ssot/` โดยอ่าน `SSOT-MANIFEST.md` ก่อนเอกสารอื่นเสมอ

## Production Gate
ห้ามผลิต Full 40 Stickers ก่อน Character Sheet Candidate ผ่านการอนุมัติเป็น `CHARACTER_SHEET_ACTIVE` และ Hero Sticker Set ผ่านการตรวจสอบ
