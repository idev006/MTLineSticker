# PROJECT CREATIVE BRIEF v1.0

## Product
LINE Sticker Set: **ผู้ใหญ่ใจดี เกษียณแล้วก็ยังเท่**

## Goal
สร้างสติ๊กเกอร์ 40 แบบที่ใช้คุยแบบสุภาพในชีวิตประจำวัน โดยมีตัวละครผู้ชายวัยผู้ใหญ่ที่ดูดี สุขุม อบอุ่น น่าเชื่อถือ และยัง active หลังเกษียณ

## Positioning
“สติ๊กเกอร์ผู้ใหญ่ใจดี สุภาพ อบอุ่น และยังดูเท่ ใช้คุยได้ทุกวัน”

## Primary Audience
- ผู้ใหญ่วัยทำงานและวัยเกษียณ
- ครอบครัว
- กลุ่มเพื่อน/เพื่อนร่วมงาน
- ผู้ใช้ที่ต้องการสติ๊กเกอร์สุภาพและเป็นมิตร

## Character Promise
ตัวละครต้องให้ความรู้สึกว่าเป็นผู้ใหญ่ที่มีประสบการณ์ พูดดี ใจดี เข้าถึงง่าย พร้อมช่วยเหลือ และยังดูทันสมัยพอสมควร

## Visual Direction
- clean warm semi-chibi
- likeness preserved but simplified for sticker readability
- grey sporty jacket/tracksuit as main outfit
- healthy posture, upright body language
- friendly smile and expressive face
- premium, simple, uncluttered rendering

## Tone of Voice
สุภาพ อบอุ่น กระชับ ไม่แข็ง ไม่วัยรุ่นจัด ไม่หยาบ และไม่เล่นมุกกับความแก่

## Product Structure
40 stickers ครอบคลุม: greeting, acknowledgement, thanks, encouragement, caring, coordination, celebration, daily reactions, and closing conversation.

## Critical Success Criteria
- ดูเป็นบุคคลต้นแบบในระดับจดจำได้
- เป็นผู้ใหญ่แต่ไม่แก่โทรม
- expression อ่านง่ายเมื่อย่อขนาด
- ทุกสติ๊กเกอร์คง character consistency
- มีข้อความที่ใช้จริงบ่อย

## Production Sequence
Creative Brief → Character Bible → Character Sheet Specification/Prompt/Negative Constraints → Character Sheet Candidate → Owner Approval → Hero 8 → QA → Full 40.
