# SET-007 CAPTION PRODUCTION TABLE v1.0

Status: **ACTIVE / PRE-HERO PRODUCTION**

Project: **ผู้ใหญ่ใจดี เกษียณแล้วก็ยังเท่**

This document defines the approved 40-caption coverage and the intended pose / expression / prop direction for each sticker. All visual production MUST follow `CHARACTER_SHEET_ACTIVE` and the active SSOT manifest.

## Global Visual Rules
- Use `CHARACTER_SHEET_ACTIVE` as the primary visual reference.
- Maintain the approved head shape, face likeness, hairstyle, body build, age treatment, grey tracksuit, and illustration language.
- Main outfit: plain grey tracksuit with white sleeve/pants side stripes, dark inner shirt, dark athletic shoes, dark watch/smartwatch.
- No logo, badge, emblem, insignia, or police marking on clothing.
- Character must look mature, healthy, strong, kind, approachable, and age-appropriate; never frail, tired, overly wrinkled, hunched, or elderly-looking.
- Captions should be large, legible, and visually integrated with the pose without covering the face or key gesture.
- Props and effects should be minimal and used only to strengthen communication.
- Transparent background is preferred for final LINE sticker production unless a later production spec says otherwise.

## Caption Groups

### A. Greeting / Opening
1. **สวัสดีครับ**  
   Pose: ยืนยิ้ม โบกมือหนึ่งข้าง  
   Expression: อบอุ่น เป็นมิตร  
   Elements: เส้น motion เล็กๆ รอบมือ

2. **สวัสดีตอนเช้าครับ**  
   Pose: ถือแก้วกาแฟ/น้ำอุ่น ยกเล็กน้อย  
   Expression: สดชื่น ยิ้มละมุน  
   Elements: แสงเช้าหรือประกายอ่อนๆ

3. **วันนี้ขอให้เป็นวันที่ดีนะครับ**  
   Pose: ชูนิ้วโป้ง อีกมือแตะอก  
   Expression: ยิ้มให้กำลังใจ  
   Elements: ประกายเล็กๆ รอบตัว

4. **คิดถึงนะครับ**  
   Pose: มือทำหัวใจเล็กๆ หรือส่งหัวใจออกไป  
   Expression: อ่อนโยน  
   Elements: หัวใจเล็ก 1–2 ดวง
