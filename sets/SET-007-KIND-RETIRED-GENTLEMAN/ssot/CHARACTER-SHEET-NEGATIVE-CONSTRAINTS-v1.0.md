# CHARACTER SHEET NEGATIVE CONSTRAINTS v1.0

Reject or regenerate if any of the following occurs:

## Age / Face
- looks elderly, frail, exhausted, sickly, or significantly older than the reference impression
- excessive wrinkles, eye bags, sagging cheeks/neck, deep facial folds
- grey/white hair added as an age device without reference support
- face becomes gaunt, bony, or overly caricatured
- default expression looks angry, stern, gloomy, or tired

## Body / Pose
- hunched back, weak posture, shuffling stance
- child-like chibi body with very short limbs
- exaggerated obesity, muscularity, or thinness
- malformed hands, duplicated fingers/limbs, inconsistent anatomy

## Identity
- likeness lost between views
- face shape, hair silhouette, eyes, or smile changes materially across the sheet
- character looks like a generic unrelated older man

## Outfit
- police uniform used as main outfit
- formal ceremonial uniform or prominent police insignia introduced
- jacket/tracksuit direction replaced by unrelated fashion
- excessive logos, patterns, or clutter

## Style
- slapstick, parody, mockery of age
- baby-face treatment that removes maturity
- hyper-realistic aging detail
- overly dramatic anime styling that obscures likeness
- inconsistent rendering style between panels

## Sheet Quality
- missing required views, expressions, gestures, outfit details, or palette
- overlapping figures that prevent silhouette review
- decorative background that interferes with evaluation
- unreadable small details or inconsistent scale
