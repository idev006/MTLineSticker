# HERO STICKER PLAN v1.0

## Goal
พิสูจน์ character consistency, readability, likeness, age treatment, pose language และ tone ก่อนผลิตครบ 40 แบบ

## Hero Set — 8 Stickers
1. **สวัสดีครับ** — warm smile + wave/wai
2. **รับทราบครับ** — polite confident nod
3. **ขอบคุณครับ** — wai / hand-on-chest gratitude
4. **สู้ๆ นะครับ** — calm encouragement gesture
5. **เดี๋ยวผมดูให้ครับ** — helpful ready-to-act pose
6. **ไม่เป็นไรครับ** — reassuring gentle hand gesture
7. **ยินดีด้วยครับ** — warm applause / celebratory smile
8. **แล้วคุยกันนะครับ** — friendly goodbye wave

## Hero QA
ทุกภาพต้องผ่าน:
- recognizable same character
- mature but not old-looking
- upright healthy posture
- grey sporty outfit consistency
- polite expression and gesture
- caption readability
- clear silhouette at LINE scale
- no visual clutter

## Gate Rule
ห้ามเดินหน้า Full 40 Production จนกว่า Owner อนุมัติ Hero Set อย่างชัดเจน
