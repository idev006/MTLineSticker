# QA CHECKLIST v1.0

ใช้ตรวจทุก Candidate ก่อน Owner Approval

## Character Identity
- [ ] same recognizable character across all views/assets
- [ ] face shape consistent
- [ ] very short neat hair consistent
- [ ] warm smile/eyes remain identifiable

## Age Treatment
- [ ] mature and experienced
- [ ] healthy, active, dignified
- [ ] not elderly-looking, frail, tired, hunched, or excessively wrinkled
- [ ] no unnecessary grey-hair aging treatment

## Body / Pose
- [ ] adult semi-chibi proportion
- [ ] healthy upright posture
- [ ] hands/anatomy clean
- [ ] gestures polite and readable

## Outfit
- [ ] grey sporty jacket/tracksuit direction maintained
- [ ] dark inner shirt and coordinated trousers consistent
- [ ] no police uniform as primary look
- [ ] no distracting logos/details

## Sticker Communication
- [ ] caption correct Thai spelling
- [ ] polite tone
- [ ] expression matches caption
- [ ] silhouette and message readable at small size
- [ ] no unnecessary visual clutter

## Production Gates
- Character Sheet: must pass all identity/age/outfit checks before becoming `CHARACTER_SHEET_ACTIVE`
- Hero Set: all 8 must pass before Full 40 production
- Full 40: each asset must conform to active visual SSOT and approved production list
