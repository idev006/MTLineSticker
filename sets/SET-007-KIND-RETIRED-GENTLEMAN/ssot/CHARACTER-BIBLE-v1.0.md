# CHARACTER BIBLE v1.0

## Character Core
Archetype: **ผู้ใหญ่ใจดี เกษียณแล้วก็ยังเท่**

บุคลิกหลัก: สุภาพ ใจดี อบอุ่น สุขุม น่าเชื่อถือ มีวุฒิภาวะ เป็นมิตร แข็งแรงสมวัย และยัง active

## Visual SSOT — OWNER LOCKED
**`CHARACTER_SHEET_ACTIVE` = Character Design Sheet ล่าสุดที่เจ้าของอนุมัติในวันที่ 2026-09-17**

ภาพดังกล่าวเป็น visual reference หลักสำหรับ Hero Sticker และสติ๊กเกอร์ทั้ง 40 ภาพ โดยต้องรักษา:
- โครงศีรษะและสัดส่วนศีรษะ
- โครงหน้าและ likeness
- ทรงผม
- รูปร่างและสัดส่วนร่างกาย
- treatment เรื่องอายุ
- ชุดวอร์มสีเทา
- ภาษาลายเส้น/การลงสีแบบการ์ตูนกึ่งสมจริงที่สะอาดและเป็นมิตร

ภาพถ่ายบุคคลจริงเป็น secondary fidelity reference ใช้ตรวจไม่ให้ likeness drift แต่ไม่ควรลบ stylization ที่ล็อกไว้ใน `CHARACTER_SHEET_ACTIVE` เว้นแต่เจ้าของสั่งแก้โดยตรง

## Identity to Preserve
- ศีรษะ **ไม่กลมเป็นทรงลูกบอล**; ให้ยึด silhouette ที่มีโครงสร้างจาก `CHARACTER_SHEET_ACTIVE`
- ใบหน้ากว้างพอดี มีมวลแก้มอย่างเป็นธรรมชาติ แต่ไม่ทำให้กลมป้อมเกินจริง
- ผมสั้นมาก เรียบร้อย ด้านข้าง/ด้านหลังสั้น
- คิ้วชัด ดวงตาใจดี สีหน้าและรอยยิ้มเป็นมิตร
- ลุคผู้ใหญ่ที่ดูสะอาด สุขภาพดี แข็งแรง และมีความมั่นใจ
- รูปร่างแน่น/แข็งแรงสมวัย มีมวลตัวพอดี ไม่ผอมแห้ง ไม่อ้วนเกินจริง

## Perceived Age Rule — OWNER LOCKED
**ห้ามออกแบบให้ดูแก่จนดูไม่ดี**

ให้ตีความวัยเป็น: mature, healthy, active, strong, dignified, approachable.

ลดรายละเอียดที่ทำให้ดูโรยราโดยไม่จำเป็น เช่น ริ้วรอยลึก ถุงใต้ตา ผิวหย่อน ร่องแก้มหนัก และ posture อ่อนแรง แต่ไม่ทำให้ดูเด็กจนสูญเสียความเป็นผู้ใหญ่

ห้าม:
- หลังค่อม/งุ้ม
- หน้าตาเหนื่อยล้า โทรม หรือเศร้าเป็น default
- เพิ่มผมหงอกเพื่อสื่อวัยโดยไม่จำเป็น
- exaggerate ความแก่เพื่อความตลก
- ทำศีรษะกลม/ป้อมเกิน visual SSOT

## Face
- Face/head shape: ยึด `CHARACTER_SHEET_ACTIVE`; structured broad oval / softly squared impression มากกว่าทรงกลม
- Eyes: อ่อนโยน อ่านอารมณ์ง่าย
- Eyebrows: ชัดแต่ไม่ดุ
- Nose: ธรรมชาติ ไม่ caricature
- Smile: natural warm smile; เป็น identity สำคัญ
- Skin treatment: สะอาด สุขภาพดี ลดริ้วรอยส่วนเกิน

## Hair
- สั้นมาก สะอาด เรียบร้อย
- ด้านข้างและด้านหลังสั้น
- ไม่ฟู ไม่แฟชั่นจัด

## Body & Proportion
- sticker-friendly stylization แบบผู้ใหญ่ โดยยึดสัดส่วนจาก `CHARACTER_SHEET_ACTIVE`
- sturdy / solid / healthy mature build
- หัวใหญ่กว่าจริงได้เพียงเล็กน้อยเพื่ออ่าน expression แต่ห้าม chibi จน likeness และ dignity หาย
- torso/แขน/ขาไม่สั้นป้อมจนดูเด็ก
- หลังตรง การเคลื่อนไหวมั่นคงและคล่องตัว

## Main Outfit — LOCKED
- plain grey sporty jacket / tracksuit
- white stripe details on sleeves and pants
- dark inner shirt
- matching grey trousers
- simple dark sporty footwear
- dark watch / smartwatch allowed
- **ห้ามมี logo, badge, emblem, patch, insignia หรือเครื่องหมายใดบนเสื้อและกางเกง**
- overall look: smart, clean, relaxed, active

ตำรวจ/เครื่องแบบราชการไม่ใช่ primary outfit สำหรับชุดนี้

## Body Language
เหมาะ: ไหว้, โบกมือ, thumbs-up, พยักหน้า, ก้มศีรษะเล็กน้อย, ปรบมือ, ท่าพร้อมช่วย, ท่าคิด, ถือไมค์/กาแฟ/โทรศัพท์/เอกสารแบบเรียบง่าย

หลีกเลี่ยง: aggressive gesture, youth-culture pose ที่แรงเกินคาแรกเตอร์, slapstick ที่ทำให้เสีย dignity

## Expression Set
ต้องรองรับอย่างน้อย: ยิ้มสุภาพ, ยิ้มอบอุ่น, รับทราบ, ดีใจ, ขอบคุณ, ให้กำลังใจ, ห่วงใย, คิด, ประหลาดใจเบาๆ, ผ่อนคลาย, ขออภัย/เกรงใจ, กล่าวลา

## Tone of Voice
สุภาพ เป็นธรรมชาติ กระชับ และใช้จริง เช่น “สวัสดีครับ”, “รับทราบครับ”, “ขอบคุณครับ”, “ไม่เป็นไรครับ”, “เดี๋ยวผมดูให้ครับ”, “เป็นกำลังใจให้นะครับ”

## Rendering
- **ยึดลายเส้นและ stylization ของ `CHARACTER_SHEET_ACTIVE`**
- clean sticker illustration
- slightly cartooned / polished semi-real character treatment
- simple shapes, clean silhouette
- readable at LINE sticker size
- background transparent for final sticker assets
- avoid visual clutter

## Visual QA / Rejection Conditions
Reject if:
- ดูแก่ โทรม อ่อนแรง หรือมีริ้วรอยเกิน visual SSOT
- likeness หายชัดเจน
- ศีรษะกลมป้อมหรือ silhouette เปลี่ยนจาก `CHARACTER_SHEET_ACTIVE`
- หน้าดุเป็น default
- รูปร่างผอม/อ้วน/เตี้ยป้อมผิดจาก visual SSOT
- มีเครื่องหมายหรือโลโก้บนชุดวอร์ม
- ชุดหลุด direction
- ดูเด็กเกินไป
- caricature แรง
- ลายเส้นหรือ rendering drift จาก `CHARACTER_SHEET_ACTIVE`
- สูญเสียความสุภาพ/อบอุ่น/แข็งแรง/เท่

## Production Rule
ทุก Hero และ Full-40 sticker ต้อง review เทียบ `CHARACTER_SHEET_ACTIVE` ก่อนผ่าน QA. หาก face/head shape, body, age treatment, outfit หรือ style drift ให้แก้ก่อนรับเข้า production set.
