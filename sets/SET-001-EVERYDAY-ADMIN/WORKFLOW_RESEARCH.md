# Workflow Research Map

## Principle
Set 01 is workflow-first. We map recurring administrative-police activities before finalizing captions. Each event should eventually record trigger, recipient, communication intent, tone, frequency hypothesis, and sticker opportunity.

## Core workflow domains
1. Start-of-day / check incoming work
2. Receive instructions / acknowledge
3. Clerical and correspondence work
4. Request and collect information
5. Coordinate people or units
6. Invitations and scheduling
7. Meetings: before / during / after
8. Assign and follow up work
9. Propose / sign / approve documents
10. Send, report and close tasks
11. Urgent / interrupting work
12. Break / human moments / safe workplace humor

## Repeating event loop
Incoming task → acknowledge → verify → request data → coordinate → wait → follow up → prepare → propose → approve/sign → send/report → revise if needed → close.

## Communication modes
- Superior-facing: respectful, concise, reliable
- Peer-facing: friendly, efficient, lightly humorous
- Cross-unit: polite, neutral, clear
- Junior/team-facing: friendly directive

## Research rule
Exact phrase frequency and work-habit assumptions remain hypotheses until validated with target users. Prefer behavioral questions such as “what were the last 10 work messages you sent?” over preference-only questions such as “what stickers do you like?”.
