# PROP BIBLE v1.0

## Purpose
กำหนดระบบพร็อพสำหรับ SET-008 เพื่อให้พร็อพช่วยสื่อความหมายของสติ๊กเกอร์โดยไม่รบกวนตัวละครหลัก

> **Core rule:** สติ๊กเกอร์ไม่ใช่ภาพวาดวิว ตัวละครหลักต้องเด่นที่สุดเสมอ พร็อพและองค์ประกอบเสริมมีหน้าที่เพียงสนับสนุนความหมาย

## Visual Priority
ลำดับความสำคัญขององค์ประกอบ:
1. Character identity
2. Facial expression / gesture
3. Caption
4. Primary prop
5. Secondary accent
6. Background cue

ห้ามสลับลำดับจนพร็อพ ฉาก หรือของตกแต่งเด่นกว่าตัวละคร

## Prop Density Rules
- 1 เฟรมควรมี **Primary Prop ไม่เกิน 1 ชิ้น**
- Secondary prop/visual cue รวมกันไม่เกิน 1–2 รายการ
- ใช้ decorative accents เท่าที่จำเป็น
- ไม่ทำ full scene, room scene, landscape, temple courtyard, garden vista หรือฉากเล่าเรื่องเต็มรูปแบบ
- หลีกเลี่ยง object clusters จำนวนมาก
- เว้น negative space รอบตัวละครและข้อความ
- ถ้าตัดพร็อพออกแล้วความหมายยังชัด ให้พิจารณาไม่ใส่พร็อพ

## Scale Rules
- Character ควรครองพื้นที่ภาพส่วนใหญ่
- Prop ต้องไม่ใหญ่หรือมี contrast สูงกว่าหน้า/ลำตัว เว้นแต่เป็นพร็อพที่ถืออยู่และจำเป็นต่อความหมาย
- Props ที่เป็นสัญลักษณ์ เช่น ?, !, ดาว, หัวใจ, เหรียญ ให้ใช้ขนาดเล็กถึงกลาง
- ห้ามใช้ foreground/background layering ซับซ้อนแบบ poster

## Prop Style
- รูปทรงอ่านง่าย
- รายละเอียดไม่จุกจิก
- สีสอดคล้องกับชุดและ caption
- หลีกเลี่ยง texture ละเอียดมาก
- ใช้ white sticker outline ร่วมกับตัวละครเมื่อต้องการแยก silhouette
- หลีกเลี่ยง photoreal prop ที่เด่นกว่าตัวละคร

## Cultural Sensitivity
พร็อพทางศาสนาและวัฒนธรรมไทยต้องใช้ในเชิงสุภาพ ไม่ล้อเลียน ไม่โอเวอร์แฟนตาซี และไม่ทำเป็นฉากศาสนสถานเต็มเฟรม

## Prop Categories

### A. Greeting / Blessing
เหมาะกับสวัสดีวันต่าง ๆ และคำอวยพร
- ดอกบัว / ดอกไม้ไทย
- แสงเช้าแบบ symbolic
- พระอาทิตย์แบบ icon
- ใบไม้
- หัวใจเล็ก
- ประกายอ่อน

### B. Merit / Spiritual
- ดอกบัว
- พวงมาลัย
- ถาดทำบุญ
- ธูปในจำนวนพอดี
- เบาะสมาธิ
- แสงอ่อนแบบ symbolic

**ห้าม:** ฉากวัดเต็มภาพ, เจดีย์ขนาดใหญ่, วิวศาสนสถานละเอียด, halo แฟนตาซีเกินจริง

### C. Health / Care
- ขวดน้ำ
- รองเท้าเดิน/ออกกำลังกาย
- ผลไม้
- แก้วน้ำอุ่น
- ผ้าห่ม
- ยาแบบเรียบง่าย
- ร่ม / ผ้าพันคอเมื่อสัมพันธ์กับข้อความ

### D. Daily Life
- โทรศัพท์
- จานอาหาร / ปิ่นโต
- ถ้วยชา
- พัด
- หมอน / ผ้าห่ม
- กระเป๋าถือ

### E. Travel
- กระเป๋าเดินทาง
- กระเป๋าถือ
- จักรยาน
- เครื่องบิน icon ขนาดเล็ก

### F. Emotion / Reaction
- ?
- !
- ดาวหมุน
- หยดเหงื่อ
- เมฆความคิด
- เส้นลม
- sparkle

### G. Prosperity
- ถุงเงิน
- เหรียญทองจำนวนพอดี
- sparkle
- ธนบัตรเชิง symbolic

**ห้าม:** กองเงินจำนวนมาก, เหรียญเต็มพื้น, ฉากคลังทอง

### H. Calm Lifestyle / Craft
- ดอกบัว
- ถาดพับดอกไม้
- ถ้วยชา
- หมอนรองนั่ง
- พัด

## Rejection Criteria
Reject หาก:
- prop ใหญ่กว่าตัวละครโดยไม่จำเป็น
- มีฉากหลังเต็มรูปแบบ
- มีวัตถุมากจนอ่าน pose ไม่ออก
- พร็อพซ้ำซ้อนกับ caption โดยไม่เพิ่มความชัด
- character silhouette แตกเพราะของตกแต่ง
- visual cue ดูเป็น poster มากกว่า sticker
- prop เพิ่มรายละเอียดจนอ่านข้อความยาก
