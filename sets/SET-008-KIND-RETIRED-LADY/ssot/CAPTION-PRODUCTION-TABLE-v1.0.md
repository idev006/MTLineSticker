- แก้ข้อ 02 จาก “บิดบาน” เป็น **“เบิกบาน”**

- ข้อ 22, 25–36 เป็น reaction/pose stickers โดยตั้งใจเว้น caption เพื่อให้ใช้ได้กว้างและลด text overload
- ข้อ 39 กำหนด caption ชัดเจนเป็น **“โอเคจ้า”**
