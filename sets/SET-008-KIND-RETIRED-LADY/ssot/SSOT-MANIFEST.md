## Decision Rules
- หาก prompt ขัดกับ Character Bible ให้ยึด Character Bible
- หากการใช้พร็อพหรือองค์ประกอบเสริมขัดกับ Prop Bible ให้ยึด Prop Bible
- หาก pose/prop ขัดกับ Caption Production Table ให้ยึด Caption Production Table และ Prop Bible ร่วมกัน
- **Sticker-first rule:** ตัวละครหลักต้องเด่นที่สุดเสมอ; ฉาก พร็อพ และ decoration ห้ามแย่งความสนใจ
- ห้ามออกแบบเป็นภาพวิวหรือ greeting poster เต็มฉาก เว้นแต่ Product Owner อนุมัติเฉพาะกรณี
- หากงานภาพสวยแต่ character drift ให้ reject
- หากข้อความไทยผิดแม้เพียงจุดเดียว ให้ reject
- หาก sticker อ่านไม่ออกเมื่อย่อขนาดใช้งานจริง ให้ revise
- Owner approval มีอำนาจสูงสุด
