# SUCCESS DESIGN GUIDELINES v1.0

## Purpose
แนวทางเชิงผลิตภัณฑ์สำหรับ SET-008 โดยสังเคราะห์จาก LINE Creators Market official guidelines, LINE Sticker Maker usage tips และเครื่องมือการจำหน่ายของ LINE

> เป้าหมายไม่ใช่แค่ “ผ่านการพิจารณา” แต่ต้อง “หยิบใช้บ่อย เข้าใจเร็ว จำตัวละครได้ และค้นพบได้ง่าย”

## 1. Utility First
LINE แนะนำสติกเกอร์ที่ใช้ง่ายในการสนทนาประจำวัน และสื่ออารมณ์/ข้อความ/ภาพได้เข้าใจง่าย

### Rule
ทุกเฟรมต้องตอบคำถาม:
- ใช้ในบทสนทนาอะไร?
- ผู้รับเข้าใจภายในประมาณ 1 วินาทีหรือไม่?
- ผู้ซื้อมีโอกาสใช้ซ้ำหรือไม่?

หากคำตอบไม่ชัด ให้ revise หรือ replace

## 2. Target-Age Usage Evidence
จากข้อมูล usage tips ของ LINE:
- “OK” เป็นหนึ่งในสติกเกอร์ที่ถูกใช้มากในทุกเพศทุกวัย
- ผู้ใช้อายุ 30+ มีแนวโน้มใช้ “ขอบคุณมาก” และ “ฝากด้วยนะ”
- ผู้ใช้อายุ 50+ ใช้ “ราตรีสวัสดิ์/ฝันดี” มากกว่ากลุ่มวัยอื่น
- คำทักทายและอารมณ์เชิงบวกที่ใช้บ่อยช่วยให้ชุดหยิบใช้ได้ง่าย

### Implication for SET-008
ต้องมี utility anchors อย่างน้อย:
- OK / โอเคจ้า
- ขอบคุณ / ขอบใจ
- ฝากด้วยนะ / รบกวนด้วยนะ
- ฝันดี / ราตรีสวัสดิ์
- สบายดี / ทักทาย
- ดูแลตัวเอง
- เดินทางปลอดภัย
- กินข้าวหรือยัง / กินข้าวกัน
- ไปก่อน / บ๊ายบาย

## 3. Character First, Not Scenery
LINE ระบุว่าวัตถุและทิวทัศน์ที่ใช้ยากในชีวิตประจำวันเป็นแนวที่ไม่แนะนำ และภาพเต็มตัวที่ยาวเกินไปอาจมองเห็นไม่ดี

### SET-008 Rule
Visual hierarchy:
1. Character
2. Face / gesture
3. Caption
4. Primary prop
5. Accent

- ห้ามทำเป็น greeting poster
- ห้ามฉากสวน/วัด/บ้าน/วิวเต็มเฟรม
- ใช้ close-up และ half-body เป็นหลักเมื่อช่วย readability
- full-body ใช้เฉพาะเฟรมที่ action ต้องใช้ร่างกาย เช่น ปั่นจักรยาน/เดินทาง

## 4. Readability at Chat Size
- ตัวอักษรต้องใหญ่
- เลี่ยงข้อความยาวหลายบรรทัด
- ใช้ outline/contrast ที่อ่านได้ทั้งพื้นแชตมืดและสว่าง
- ทดสอบใน LINE Simulator ก่อน submit
- ทำ thumbnail test ที่ขนาดใช้งานจริง

### Internal Rule
หาก caption ยาวเกินจนต้องลดตัวอักษรมาก ให้ย่อข้อความก่อนเพิ่ม decoration

## 5. Variety Without Character Drift
LINE ไม่แนะนำชุดที่ขาดความหลากหลาย

ความหลากหลายของ SET-008 ให้เกิดจาก:
- emotion
- gesture
- crop
- pose
- Thai costume color
- prop
- text placement

แต่ต้องไม่เปลี่ยน:
- facial identity
- age
- personality
- core illustration style

## 6. Caption Portfolio Balance
สำหรับ 40 ภาพ ให้กระจายเป็น:
- 7 weekday blessings
- 8–10 high-frequency conversation utilities
- 6–8 care / health / family messages
- 6–8 emotional reactions
- 4–6 retirement-life / lifestyle actions
- 2–4 merit / spiritual blessings

ไม่ควรให้ reaction แบบไม่มีข้อความกินพื้นที่มากจน utility phrases หายไป

## 7. “Send Again” Test
ก่อนอนุมัติแต่ละเฟรม:
- ใช้ได้สัปดาห์ละหลายครั้งหรือไม่?
- ใช้กับคนหลายประเภทได้หรือไม่?
- ถ้ามีชุดอื่นอยู่แล้ว เหตุผลอะไรที่ผู้ใช้จะเลือกชุดนี้?
- ตัวละครมีน้ำเสียงเฉพาะตัวหรือไม่?

## 8. Discoverability
LINE Creators Market มี suggestion tags ซึ่งช่วยให้สติกเกอร์ถูกเสนอเมื่อผู้ใช้พิมพ์คำที่สัมพันธ์กัน

### Action
หลังจำหน่าย:
- ตรวจ auto-generated tags
- แก้ tags ให้ตรง intent ของแต่ละเฟรม
- ให้คำสำคัญตรงกับภาษาใช้งานจริง
- ใช้ข้อมูลจำนวนการส่งและยอดขายเพื่อปรับชุดถัดไป

## 9. Main Image / Thumbnail
Main และ thumbnail ต้องสะท้อน character จริงในชุด และไม่แตกต่างจาก sticker content อย่างเห็นได้ชัด

### SET-008
Main image ควรใช้:
- face ที่จำง่าย
- warm smile
- Thai outfit
- clean silhouette
- minimal text หรือไม่มีข้อความ

Thumbnail ต้อง recognizable แม้เล็กมาก

## 10. Rights / Review
- ต้องมีสิทธิ์ใช้ภาพอ้างอิงบุคคล
- ตรวจสะกดไทยทุกคำ
- หลีกเลี่ยงข้อความ/ภาพที่เป็นโฆษณา
- ไม่คัดลอก sticker ที่จำหน่ายอยู่แล้ว
- ตรวจ Main/Tab/Sticker consistency

## 11. Commercial Success Loop
หลังเปิดขาย:
1. Promote ผ่านช่องทางที่เจ้าของมีอยู่
2. ตรวจยอดขาย
3. ตรวจจำนวนครั้งที่ถูกส่ง
4. ดูว่า caption ใดถูกใช้มาก
5. ใช้ข้อมูลจริงวาง SET-009 / sequel
6. พิจารณา LINE Stickers Premium เมื่อเข้าเกณฑ์อายุการขาย

## 12. SET-008 Pre-Character-Sheet Conclusions
ก่อนสร้าง Character Sheet:
- character ต้องอ่านชัดใน close-up/half-body
- สไตล์ต้องรองรับทั้งคำอวยพรและ reaction
- costume ต้องสวยแต่ไม่แย่งหน้า
- props ต้อง isolate และเรียบง่าย
- expression library ต้องชัดขึ้นกว่าความสมจริงของภาพอ้างอิง
- ห้ามเติม scenery เพื่อ “ทำให้ภาพสวย”
- ความสวยต้องมาจาก character, gesture, costume, typography และ negative space
