## Sticker-First Rule
This sheet is preparation for LINE stickers.

Do NOT create scenic compositions.
Do NOT create a garden, temple, house, room, landscape, sunrise scene, or greeting-card environment.
Do NOT use decorative foreground layers.
Do NOT fill empty areas with flowers, buildings, clouds, gold ornaments, or scenery.

The character must remain the strongest visual element.
Props must be secondary, simple, and isolated.
Use ample negative space.
Use only minimal labels if needed.

## Background
