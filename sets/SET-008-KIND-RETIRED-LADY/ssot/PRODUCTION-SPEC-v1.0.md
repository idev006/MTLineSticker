# PRODUCTION SPEC v1.0

## Product Type
LINE Static Stickers

## Final Deliverables
- Sticker images: 40 PNG
- Main image: 240 x 240 px PNG
- Chat thumbnail: 96 x 74 px PNG

## Sticker Constraints
- Final sticker image maximum: 370 x 320 px
- PNG
- RGB
- transparent background
- even-numbered width and height
- at least 72 dpi
- each image <= 1 MB
- maintain practical margin around artwork

## Master Production
Recommended working master per frame:
- 512 x 512 px or larger
- transparent background
- safe padding 20 px
- scale down/export only after visual QA

## Sheet Workflow
For review sheets:
- 5 columns x 2 rows
- 10 frames per sheet
- 4 sheets total
- each review frame 512 x 512 master target
- visible frame border for QA only
- final exported sticker must not contain review-grid border

## Typography
- Thai letters large and legible
- avoid overly thin fonts
- prioritize words over decoration
- caption must remain readable at chat size
- no spelling errors
- do not let text touch crop edge

## Sticker Construction
Preferred hierarchy:
Character > gesture/expression > caption > prop > decorative accent

## Background
Final stickers: transparent.
No full scenic greeting-card background unless specifically required for a frame and still remains legible.

## External Reference
Official LINE Creators Market static-sticker guideline should be rechecked before final submission.
