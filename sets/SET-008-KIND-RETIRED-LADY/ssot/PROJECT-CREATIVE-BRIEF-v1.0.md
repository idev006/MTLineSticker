# PROJECT CREATIVE BRIEF v1.0

## Project
SET-008 — Kind Retired Lady

## Audience
ผู้ใช้หญิงวัยหลังเกษียณ ใช้ส่งหาเพื่อน ลูกหลาน ญาติ และคนใกล้ชิด

## Character Positioning
“ผู้ใหญ่ใจดี ส่งความห่วงใยและพรดี ๆ ในทุกวัน”

## Personality
- ใจดี มีเมตตา
- สุภาพ อบอุ่น
- สดใสแบบผู้ใหญ่
- มีอารมณ์ขันเล็กน้อย
- มีความเป็นไทยร่วมสมัย
- ไม่ดูเด็ก ไม่ดูการ์ตูนจนเกินไป
- ไม่ดูชรา โทรม หรือเคร่งขรึมเกินไป

## Visual Direction
- Semi-realistic illustration / refined cartoon
- ใบหน้าต้องอ้างอิงนางแบบจาก source images
- สีหน้าอิ่มเอิบ เป็นมิตร มีชีวิตชีวา
- ชุดไทยหลายรูปแบบและหลายสี
- ใช้ props เพื่อช่วยสื่อสารความหมาย แต่ไม่แย่งตัวละคร
- พื้นหลัง final sticker โปร่งใส
- ใช้ white outline รอบตัวละคร/props ตามความเหมาะสมเพื่ออ่านบนแชตง่าย

## Communication Pillars
1. คำอวยพรประจำวัน
2. ความห่วงใย/สุขภาพ
3. การตอบรับ/ขอบคุณ
4. ชีวิตประจำวัน
5. อารมณ์และ reaction
6. กิจกรรมหลังเกษียณ
7. ธรรมะ/บุญ/ความร่มเย็น

## Tone of Voice
ใช้ภาษาไทยเป็นธรรมชาติ อ่อนโยน และเหมาะกับผู้ใหญ่ เช่น “จ้า”, “นะจ๊ะ” ใช้พอเหมาะ ไม่หวานหรือเด็กเกินไป

## Non-goals
- ไม่ทำเป็นภาพโปสเตอร์อวยพรที่มีฉากซับซ้อน
- ไม่ใช้ข้อความยาวจนกินพื้นที่
- ไม่ให้ชุดไทยหรือ props ทำให้ character identity เปลี่ยน
- ไม่สร้าง stereotype ผู้สูงวัยแบบเจ็บป่วย/แก่ชราเป็นหลัก
