# CHARACTER SHEET SPECIFICATION v1.1

## Project
SET-008 — KIND-RETIRED-LADY

## Purpose
สร้าง Character Sheet Candidate สำหรับตัวละครหลักของชุดสติ๊กเกอร์ LINE นี้ เพื่อใช้เป็น Visual SSOT ก่อนเริ่ม Hero Sticker และ Full Production 40 stickers

Character Sheet ต้องทำหน้าที่เป็น:
- Visual identity reference
- Expression reference
- Costume system reference
- Prop interaction reference

## Core Principle
Character Sheet นี้ไม่ใช่โปสเตอร์ ไม่ใช่ภาพวิว และไม่ใช่ finished sticker sheet

Mandatory:
- ตัวละครเด่นที่สุด
- ไม่มี scenic background
- ไม่มี greeting-card composition
- ไม่มีองค์ประกอบตกแต่งรบกวนตัวละคร
- ไม่มีข้อความยาว
- มี negative space มากพอ

## Character Identity
- ผู้หญิงไทยวัยหลังเกษียณ
- ใจดี มีเมตตา อบอุ่น สุภาพ สง่างาม
- ดูสุขภาพดี
- เป็นผู้ใหญ่ ไม่เด็ก ไม่ chibi
- ไม่ดูโทรม
- ต้องเป็นคนเดียวกันทุกช่อง

## Face Identity
รักษา:
- โครงหน้า
- คิ้ว
- ดวงตา
- จมูก
- ปาก
- รอยยิ้ม
- age impression
- gentle demeanor

Reject:
- หน้าเปลี่ยนคน
- อายุแกว่ง
- ดูสาวเกินไป
- ดูชราเกินต้นแบบ
- anime/chibi
- over-glamour

## Hair
- ผมดำ/ดำเทาอย่างเป็นธรรมชาติ
- เกล้าเรียบร้อย
- เครื่องประดับผมไทยแบบสุภาพได้เล็กน้อย

## Body
- สัดส่วนผู้ใหญ่สมส่วน
- ท่าทางอ่านง่าย
- ไม่หัวโตตัวเล็ก
- ไม่ exaggerated

## Required Views
1. Front
2. 3/4 Left
3. 3/4 Right
4. Side
5. Back

## Required Expressions
1. Neutral warm smile
2. Joyful smile
3. Grateful
4. Caring / concerned
5. Curious
6. Surprised
7. Mild fear
8. Excited
9. Mild anger / cute sulking
10. Thoughtful
11. Confused
12. Peaceful meditation
13. Sleepy / sleeping

## Costume Board
อย่างน้อย 6 สี:
- Yellow / Gold
- Pink
- Green
- Orange / Gold
- Blue
- Purple

ชุดต้องอยู่ในระบบชุดไทย / ไทยประยุกต์ / ผ้าไหมไทยแบบสุภาพ

## Prop Board
- Lotus
- Tea cup
- Merit offering tray
- Travel bag / suitcase
- Bicycle
- Food plate / tiffin
- Phone
- Pillow / blanket
- Money bag / coin cue
- Meditation cushion
- Fan

## Interaction Studies
อย่างน้อย:
- holding lotus
- holding tea cup
- carrying merit tray
- traveling with suitcase
- bicycle interaction
- inviting to eat
- using phone
- meditation

## Layout
- clean reference board
- neutral light background
- consistent scale
- clear sections
- ample negative space
- labels permitted
- no poster framing
- no scenery

## Sticker-First Visual Rule
ตัวละคร > expression/gesture > costume > prop > decoration

พร็อพต้องไม่แย่งหน้า ท่าทาง หรือ silhouette
