## Sticker-First Rules
- Character dominates every frame
- Expression reads before props
- Props secondary only
- Transparent background
- No decorative scenic composition
- No greeting-card framing
- Large readable Thai text
- White sticker outline when helpful
- Maintain ample negative space
- Avoid full-body unless action requires it

## Hero Sheet Review Layout
- 4 columns x 2 rows
- each frame visually isolated
- clean grid for review only
- transparent or neutral review background
- frame number visible outside final artwork
- final sticker exports will not include grid borders

## Approval Criteria
- facial identity consistent in all 8
- age stable
- Thai costume system consistent
- captions exact and readable
- hands/anatomy correct
- prop restraint passes
- no scenic clutter
- each sticker understandable within about 1 second
- Product Owner approval required before Full 40
