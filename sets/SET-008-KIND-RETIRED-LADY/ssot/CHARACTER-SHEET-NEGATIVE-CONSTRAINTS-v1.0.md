# CHARACTER SHEET NEGATIVE CONSTRAINTS v1.0

Reject output if any of these occur:

## Identity
- face changes between panels
- age changes significantly
- looks like a teenager/young adult
- becomes excessively elderly/frail
- strong beautification that removes source identity

## Style
- chibi proportions
- anime eyes
- childish kawaii treatment
- caricature distortion
- plastic doll skin
- heavy glamour makeup
- 3D toy look unless explicitly approved

## Costume
- non-Thai fantasy costume
- historically incoherent mashups presented as exact historical dress
- overly revealing outfit
- costume overwhelms face/pose readability

## Anatomy
- extra fingers
- fused fingers
- broken wrists
- duplicated limbs
- impossible joints

## Production
- poster backgrounds
- clutter
- tiny unreadable detail
- random text
- malformed Thai text
