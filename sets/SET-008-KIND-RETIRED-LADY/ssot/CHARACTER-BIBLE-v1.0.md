# CHARACTER BIBLE v1.0

## Core Identity
ตัวละครหญิงไทยวัยหลังเกษียณ อ้างอิงใบหน้าจากภาพต้นแบบที่ Product Owner ให้ไว้

### Identity Locks
- ผู้หญิงไทยวัยหลังเกษียณ
- ใบหน้าดูใจดี สุภาพ อิ่มเอิบ
- ทรงผมเกล้าสุภาพแบบผู้ใหญ่
- รูปร่างสมส่วน
- บุคลิกมั่นคง มีศักดิ์ศรี แต่เข้าถึงง่าย
- อายุภาพรวมต้องคงที่ทุกเฟรม
- ไม่ rejuvenate จนดูวัยสาว และไม่เพิ่มริ้วรอยจนดูแก่เกินต้นแบบ

## Face
- รักษารูปหน้า โครงคิ้ว ดวงตา จมูก ปาก และรอยยิ้มให้สัมพันธ์กับ source image
- รอยยิ้มเล็กถึงปานกลางเป็น default
- แววตาอบอุ่น
- expression ต้องเปลี่ยนได้โดยไม่เปลี่ยนคน

## Hair
- ผมสีดำ/ดำเทาอย่างเป็นธรรมชาติ
- เกล้าเรียบร้อย
- อนุญาตเครื่องประดับผมไทย ดอกไม้ มุก หรือปิ่นแบบสุภาพ

## Costume System
ใช้ “ชุดไทย” เป็น wardrobe system ไม่ล็อกเพียงชุดเดียว

แนวทางที่ใช้ได้:
- ชุดไทยเรือนต้น / เรียบง่าย
- ชุดไทยจิตรลดา / สุภาพกลางวัน
- ชุดไทยอมรินทร์ / ทางการขึ้น
- ชุดไทยประยุกต์
- ผ้าไหมไทย เสื้อแขนยาวหรือคอตั้ง + ผ้านุ่ง/ซิ่น
- สไบแบบสุภาพ

สีสามารถเปลี่ยนตามอารมณ์/วัน แต่ต้องรักษาความสง่างาม

## Color Logic
- Monday: เหลือง/ทอง
- Tuesday: ชมพู
- Wednesday: เขียว
- Thursday: ส้ม/ทอง
- Friday: ฟ้า/น้ำเงิน
- Saturday: ม่วง
- Sunday: แดง/ครีม/อบอุ่น
- Other stickers: ใช้สีหลากหลายแต่คุม saturation ไม่ให้ฉูดฉาดจนเสียบุคลิก

## Expression Range
ยิ้ม, ขอบคุณ, ห่วงใย, สงสัย, ตกใจ, กลัว, ตื่นเต้น, โกรธแบบน่ารัก, คิดหนัก, มึนงง, ป่วย, รีบ, ชิล, ไม่รู้ไม่ชี้, โบกมือลา, โอเค

## Body Language
- มือและแขนต้องอ่านง่าย ไม่บิดผิดธรรมชาติ
- ท่าทางต้องชัดแม้ย่อเป็น sticker size
- silhouette ของตัวละครต้องอ่านได้ก่อนพร็อพและ decoration
- ใช้ close-up / half-body / 3/4 body / full-body ตามความเหมาะสม ไม่บังคับ full-body ทุกเฟรม

## Sticker-First Composition Rule
**สติ๊กเกอร์ไม่ใช่ภาพวาดวิวหรือ greeting poster**

ลำดับความเด่นทางสายตา:
1. Character identity
2. Facial expression / gesture
3. Caption
4. Primary prop
5. Secondary cue
6. Background accent

ข้อกำหนด:
- ตัวละครต้องเป็น focal point หลักเสมอ
- ห้ามสร้างฉากเต็ม เช่น สวน วัด บ้าน ห้อง หรือ landscape โดยไม่จำเป็น
- ห้าม foreground/background objects ซ้อนหลายชั้น
- ใช้ negative space ให้เพียงพอ
- decorative element ต้องลดได้หากรบกวนหน้า pose หรือ caption
- ถ้าความหมายอ่านได้โดยไม่ใช้ prop ให้พิจารณาตัด prop ออก

## Props
พร็อพทั้งหมดให้ยึด PROP-BIBLE-v1.0.md เป็นแหล่งอ้างอิงหลัก

ตัวอย่าง prop ที่อนุญาต:
lotus, พวงมาลัย, ถาดทำบุญ, กระเป๋าเดินทาง, จักรยาน, ถ้วยชา, อาหาร, เบาะสมาธิ, ยา/แก้วน้ำแบบเรียบง่าย, โทรศัพท์, ดอกไม้, ร่ม, กระเป๋าถือ, ถุงเงิน/เหรียญในเชิงสัญลักษณ์

## Forbidden Drift
- หน้าเปลี่ยนคน
- สัดส่วน chibi เด็กเกินไป
- ตาโตแบบอนิเมะ
- ผิวเรียบพลาสติก
- แต่งหน้าหนัก
- เครื่องแต่งกายแฟนซีที่ไม่ใช่ไทย
- มือ/นิ้วผิดรูป
- สีหน้าโกรธน่ากลัว
- prop หรือฉากเด่นกว่าตัวละคร
- composition แบบโปสเตอร์/ภาพวิว
