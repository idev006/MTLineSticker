# CHARACTER BIBLE v1.0

## Core Identity
ตัวละครหญิงไทยวัยหลังเกษียณ อ้างอิงใบหน้าจากภาพต้นแบบที่ Product Owner ให้ไว้

### Identity Locks
- ผู้หญิงไทยวัยหลังเกษียณ
- ใบหน้าดูใจดี สุภาพ อิ่มเอิบ
- ทรงผมเกล้าสุภาพแบบผู้ใหญ่
- รูปร่างสมส่วน
- บุคลิกมั่นคง มีศักดิ์ศรี แต่เข้าถึงง่าย
- อายุภาพรวมต้องคงที่ทุกเฟรม
- ไม่ rejuvenate จนดูวัยสาว และไม่เพิ่มริ้วรอยจนดูแก่เกินต้นแบบ

## Face
- รักษารูปหน้า โครงคิ้ว ดวงตา จมูก ปาก และรอยยิ้มให้สัมพันธ์กับ source image
- รอยยิ้มเล็กถึงปานกลางเป็น default
- แววตาอบอุ่น
- expression ต้องเปลี่ยนได้โดยไม่เปลี่ยนคน

## Hair
- ผมสีดำ/ดำเทาอย่างเป็นธรรมชาติ
- เกล้าเรียบร้อย
- อนุญาตเครื่องประดับผมไทย ดอกไม้ มุก หรือปิ่นแบบสุภาพ

## Costume System
ใช้ “ชุดไทย” เป็น wardrobe system ไม่ล็อกเพียงชุดเดียว

แนวทางที่ใช้ได้:
- ชุดไทยเรือนต้น / เรียบง่าย
- ชุดไทยจิตรลดา / สุภาพกลางวัน
- ชุดไทยอมรินทร์ / ทางการขึ้น
- ชุดไทยประยุกต์
- ผ้าไหมไทย เสื้อแขนยาวหรือคอตั้ง + ผ้านุ่ง/ซิ่น
- สไบแบบสุภาพ

สีสามารถเปลี่ยนตามอารมณ์/วัน แต่ต้องรักษาความสง่างาม

## Color Logic
- Monday: เหลือง/ทอง
- Tuesday: ชมพู
- Wednesday: เขียว
- Thursday: ส้ม/ทอง
- Friday: ฟ้า/น้ำเงิน
- Saturday: ม่วง
- Sunday: แดง/ครีม/อบอุ่น
- Other stickers: ใช้สีหลากหลายแต่คุม saturation ไม่ให้ฉูดฉาดจนเสียบุคลิก

## Expression Range
ยิ้ม, ขอบคุณ, ห่วงใย, สงสัย, ตกใจ, กลัว, ตื่นเต้น, โกรธแบบน่ารัก, คิดหนัก, มึนงง, ป่วย, รีบ, ชิล, ไม่รู้ไม่ชี้, โบกมือลา, โอเค

## Body Language
มือและแขนต้องอ่านง่าย ไม่บิดผิดธรรมชาติ
ท่าทางต้องชัดแม้ย่อเป็น sticker size

## Props
lotus, พวงมาลัย, ถาดทำบุญ, กระเป๋าเดินทาง, จักรยาน, ถ้วยชา, อาหาร, เสื่อ/เบาะสมาธิ, ยา/ผ้าประคบแบบเบา ๆ, โทรศัพท์, แว่นอ่านหนังสือ, ดอกไม้, ร่ม, กระเป๋าถือ, ธนบัตร/ถุงเงินในเชิงสัญลักษณ์

## Forbidden Drift
- หน้าเปลี่ยนคน
- สัดส่วน chibi เด็กเกินไป
- ตาโตแบบอนิเมะ
- ผิวเรียบพลาสติก
- แต่งหน้าหนัก
- เครื่องแต่งกายแฟนซีที่ไม่ใช่ไทย
- มือ/นิ้วผิดรูป
- สีหน้าโกรธน่ากลัว
