# DECISION LOG — น้องเข้ นสต. v0.3.0

## Owner decisions
OWNER-01 อนุญาตเดินหน้าหน้าที่ GEM A; OWNER-02 กำหนด GitHub SSOT และชุดนักเรียนนายสิบตำรวจหัวจระเข้; OWNER-03 ยืนยันใช้ตัวการ์ตูนจากภาพล่าสุดทั้งชุด หลักฐานถ้อยคำตรงตัวอยู่ใน approvals.json ทุกข้อเป็นคำสั่งกำกับโครงการ ไม่ใช่ receipt อนุมัติภาพ candidate ที่สร้างก่อนหน้า

## Assumptions
ชื่อชุด จำนวน 40 ภาพ ฮีโร่ F18 caption ทั้งหมด และสัดส่วนหัวขยายพออ่านเป็นข้อเสนอการออกแบบที่เดินหน้าตามบริบทเดิม ยังไม่ถือ OWNER_LOCKED ตีความข้อความเริ่มต้น “ชอบเค้กโชว์สาว” เป็น “ชอบเก๊กโชว์สาว” ตามมุกภาพและงานที่ดำเนินต่อ รายละเอียดชุดกากีเป็น candidate direction ไม่ยืนยันโรงเรียนใด

## Open dependencies
- DEP-001 [OPEN] ผลกระทบ: ยังไม่มี Character Sheet ที่เจ้าของอนุมัติ ผูกกับ hash จึงไม่ปลด Gate A ผู้รับผิดชอบ: Product Owner ร่วมกับผู้สร้าง Character candidate ขั้นต่อไป: ใช้เอกสาร 02_CHARACTER สร้าง/แก้ candidate โดยอิง REF01 แล้วให้เจ้าของตรวจภาพและบันทึกการอนุมัติ
- DEP-002 [OPEN] ผลกระทบ: รูปมีมไม่มีชุดนักเรียนนายสิบตำรวจ จึงยังยืนยันรายละเอียดเครื่องหมายบนชุดไม่ได้ ผู้รับผิดชอบ: Product Owner และ GEM A ขั้นต่อไป: ตรวจชุดบน candidate กับตัวอย่างชุดจริง หรือให้เจ้าของกำหนดรายละเอียดที่ยอมรับอย่างชัดเจนก่อนล็อก
- DEP-003 [OPEN] ผลกระทบ: validator ส่วนกลางรุ่นเดิมรับ contract 1.0.0 ไม่ตรง envelope 1.3.0 จึงห้ามส่งเข้าระบบนั้นโดยอ้างผ่าน ผู้รับผิดชอบ: ผู้ดูแล integration A/B ขั้นต่อไป: ตรวจ adapter/schema ที่รองรับ 1.3.0 ก่อน machine ingestion; ช่วงนี้รับเอกสารเชิงมนุษย์และเตรียม Character ได้

## Change impact
v0.3.0 เติมเอกสารเต็มมาตรฐาน 31 ไฟล์และภาพ reference จริง รักษา caption 40 ข้อเดิม ปรับ F06 จากพับแขนเป็นกำหมัดเพราะเสื้อแขนสั้น และ F20 จากปิดปากเพื่อนเป็นยกมือห้ามเพื่อให้ gesture ชัด ไม่เปลี่ยน intent ยกเลิกข้อเสนอร่างสัตว์มีหาง/3ชุดเดิม คงไฟล์เก่าเป็นประวัติและชี้ canonical revision นี้
