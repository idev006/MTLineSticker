# น้องเข้ นสต. — SSOT สำหรับ GEM A / GEM B
Revision 0.2.0 | SET-NONG-KHE-NST-01

## คำสั่งล่าสุดของเจ้าของ (มีอำนาจเหนือบรีฟ v0.1)
ตัวละครต้องเป็น **ร่างกายคน สวมชุดนักเรียนนายสิบตำรวจ หัวจระเข้ตามภาพ 1000021401.jpg** ไม่ใช่ตัวจระเข้ ไม่มีหาง มือเท้าเป็นมนุษย์ รักษารูปหัว ปากยาว ผิวเกล็ด ตา และรอยยิ้มจากภาพอ้างอิง ยกเลิกข้อเสนอชุดขาวผูกไทและการแบ่ง 3 ชุดเดิม ใช้ชุดนักเรียนเป็นชุดหลักทุกเฟรม รายละเอียดเครื่องหมายต้องอิงหลักฐานจริง ไม่สร้างยศขึ้นเอง

## เอกสารหลัก
- handoff.json: ข้อกำหนดคาแรกเตอร์ สเปกผลิต กรอบ 592x512 แผน 5 ชีท x 8 และสถานะ Gate A
- frames.csv: รหัส F01–F40 ข้อความตรงตัว ความหมาย ท่าทาง และตำแหน่งบนชีท
- approvals.json: คำสั่งเจ้าของและสถานะอนุมัติภาพ แยกอนุมัติข้อกำหนดจากอนุมัติภาพจริง
- QA.json: หลักฐานตรวจข้อมูล และรายการที่ยังไม่ได้ทดสอบ
- SHA256SUMS.txt: hash เอกสารแต่ละไฟล์ ยกเว้นตัว checksum เอง

## วิธีสื่อสารและแบ่งหน้าที่
ทั้ง GEM A และ GEM B ต้องอ่านโฟลเดอร์นี้จาก GitHub ล่าสุดก่อนทำงาน และบันทึก commit SHA ที่อ่านไว้ใน run receipt ถ้าข้อมูลใน ZIP v0.1 หรือแชทเก่าขัดกัน ให้ใช้คำสั่ง OWNER-02 ที่บันทึกที่นี่ GEM A ดูแลคาแรกเตอร์เชิงข้อกำหนด intent ข้อความ mapping และ Gate A; GEM B รับผลิตฮีโร่/ชีท ตรวจภาพจริงและ cutter เมื่อผ่าน gate ที่เกี่ยวข้อง หากพบข้อขัดแย้งให้ RETURN_TO_GEM_A พร้อม frame ID สาเหตุและ revision ห้ามเปลี่ยนข้อกำหนดเอง

## ภาพอ้างอิง
ภาพ 1000021401.jpg อ่านได้ในแชท/รันปัจจุบัน บันทึก SHA256 และ Library ID ใน handoff.json แต่ **JPEG ยังไม่ได้อัปโหลดเข้า GitHub** ข้อความในเอกสารไม่เท่ากับมีไฟล์ภาพ GEM B รันใหม่ต้องขอไฟล์แนบ/เข้าถึงภาพและตรวจ hash ก่อนใช้ ห้ามอ้างว่ามี approved Character จากภาพมีมนี้

## ฮีโร่ F18 — เก๊กก่อน
ร่างคนชุดนักเรียน หัวจระเข้ตาม REF01 อกผายจัดปกเสื้อ ยิ้มเก๊ก แต่แอบมือสั่นเมื่อเห็นเงาครูฝึก ภาพต้องอ่านง่ายในแชท ไม่เพิ่มฉากร้านหรือโลโก้ ทุกหัวใจ ข้อความและเอฟเฟกต์ต้องรวมในไดคัท
