# HERO PLAN — น้องเข้ นสต. v0.5.0

## Hero selection
เลือก F18 “เก๊กก่อน” เป็นข้อเสนอฮีโร่เพราะรวมลายเซ็นความเท่กับความลนไว้ในภาพเดียว ทางเลือก F09 ดูหล่อชัดแต่ขาด punchline; F25 ครูฝึกมา! สื่อชีวิตฝึกดีแต่ไม่สื่อคนคุย จึงเก็บ F18 เป็นตัวแทนหลัก ทั้งหมดยังรอ owner Hero approval

## Pose and expression
ร่างคนชุดนักเรียนหัว REF01 อกผายจัดปกเสื้อ ตาปรือยิ้มมั่นใจ แต่มือสั่นและเหงื่อหนึ่งเม็ด เงาครูฝึกเล็กเป็นบริบทรองไม่ให้ดูเป็นตัวละครหลักอีกตัว ห้ามเพิ่มหางหรือเสื้อไทดำ ข้อความ “เก๊กก่อน” ชัดหนึ่งถึงสองบรรทัด

## Readability
ลำดับสายตาหัวจระเข้→ท่าจัดปกเสื้อ→ข้อความ→เงารอง ลดเงาหากภาพรกแต่ต้องส่ง GEM A พิจารณาก่อนตัด punchline จัดให้เห็นมือคนชัด ทดลองดูภาพย่อขนาดแชทก่อนส่งเจ้าของ

## Approval criteria
GEM B เริ่มหลัง Character active และ Gate A พร้อม ตรวจหัว/ชุด/pose/caption ตรงทั้งหมด แสดงภาพจริงให้เจ้าของอนุมัติและผูก hash จึงเปิด batch ถ้าแก้หัวหรือชุดระหว่าง Hero ให้กลับ Character gate ไม่อนุมัติจากชื่อไฟล์หรือคำว่าสวยที่ไม่ระบุภาพ
