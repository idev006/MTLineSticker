# CHARACTER BIBLE — น้องเข้ นสต. v0.3.0

## Identity and anatomy
น้องเข้เป็นตัวละครหัวจระเข้บนร่างมนุษย์ชายวัยผู้ใหญ่ อยู่ระหว่างศึกษาเป็นนักเรียนนายสิบตำรวจ หัวอิงภาพบนของ REF01: ปากยาวมนกว้าง จมูกปลายมน ตาอยู่สูงมีสันเปลือกตา เกล็ดหยาบเทาเขียว คางเหลืองเทา ใช้ร่างคนแข็งแรงตามมีม ไม่มีหางหรือขาสัตว์ สัดส่วนเสนอลำตัวประมาณห้าหัวรวมความสูงเพื่อให้หัวอ่านชัด ยังต้องตรวจ candidate ก่อนล็อกค่าจริง

## Personality and behavior
ขี้เก๊ก ยิ้มมุมปาก อกผายเมื่อมีคนคุย แต่เขินง่ายและหมดแรงจากฝึก เป็นมิตรกับเพื่อนและให้กำลังใจกัน ความขำมาจากความต่างระหว่างภาพลักษณ์เท่กับความรู้สึกจริง ไม่ใช้การบังคับจับกุม ข่มขู่ หรือล้อรูปร่างผู้หญิงเป็นมุก

## Style and materials
เลือก 3D กึ่งสมจริงที่ยังเห็น anatomy ใกล้ REF01 ไม่ปรับเป็น baby crocodile สกินเทาเขียวไม่เขียวสดเรืองแสง ผ้ากากีด้านเห็นตะเข็บแต่ไม่มาก รองเท้าดำมีเงาเล็กน้อย แสงหลักนุ่มด้านหน้าเพื่อไม่ให้ตาดำ ภาพตัวอย่างเพื่อ review ใช้พื้นเรียบ ส่วน master ใช้ alpha จริง

## Wardrobe and accessories
ชุดนักเรียนนายสิบตำรวจเป็นข้อกำหนดจากเจ้าของ เสนอเสื้อเชิ้ตกากีแขนสั้น กระเป๋าอกสองข้าง กางเกงขายาวกากี เข็มขัดดำ รองเท้าดำเป็น candidate แบบเบื้องต้น DEP-002: ไม่มีภาพชุดจริงจึงยังยืนยันอินทรธนู ป้ายชื่อ ตรา หมวกและเลขรุ่นไม่ได้ ไม่เติมตราหรือยศสมมติ อุปกรณ์ภาพใช้ตาม props ราย ID เท่านั้น

## Forbidden drift
ห้ามนำเสื้อขาวไทดำจากมีมมาแทนชุดนักเรียน ห้ามหาง มือเกล็ด อุ้งเท้า ปากสั้น ตากลมโตแบบเด็กตลอดชุด ห้ามเปลี่ยนหัวระหว่าง view ห้ามแผลในภาพล่าง โลโก้ร้าน ฉากคนเดินผ่าน ชื่อโรงเรียนหรือยศตำรวจสำเร็จการศึกษา ภาพ candidate ที่ยังไม่อนุมัติไม่เป็นหลักแทน REF01
