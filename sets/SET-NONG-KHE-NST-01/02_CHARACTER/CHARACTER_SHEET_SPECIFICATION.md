# CHARACTER_SHEET_SPECIFICATION — น้องเข้ นสต. v0.4.0

## Views and expressions
หนึ่งแผ่นแนวนอน ภาพหลักยืนกางแขนฝ่ามือขึ้นตามภาพบน REF01 เต็มตัวขนาดใหญ่ พร้อมมุมหน้า สามส่วน ข้างและหลังขนาดรองในชุดเดียวกัน สีหน้าหลักนิ่งกวนแบบต้นฉบับ ยังไม่เพิ่มแถวสีหน้าเขินตาโตหรือการ์ตูน เพราะต้องตรวจความเหมือนก่อน

## Consistency criteria
เทียบกะโหลก ความกว้าง/ยาวปาก ตำแหน่งตา เปลือกตา เกล็ด คอ และสัดส่วนร่างกับ REF01 ไม่ใช้candidateเดิม มือคนถูกต้อง เสื้อขาวแขนยาว ปกติดเม็ดคอ ปมไทน้ำเงินเข้มแนบคอ กางเกงกากีและเข็มขัดดำตรงทุกมุม

## Composition
พื้นขาวหรือเทาอ่อนเรียบ ไม่ฉากร้าน ภาพหลักซ้ายประมาณครึ่งแผ่น ขวาวางสี่มุมชัดแยกกัน ไม่กางแขนจนถูกตัด ป้ายเล็ก CHARACTER CANDIDATE 03 เท่านั้น ภาพหลักแสดงshapeจากต้นฉบับ มุมหลังเป็นส่วนอนุมานให้ตรวจ ไม่ใส่คำว่า APPROVED

## Approval scope
OWNER-05 ยืนยันข้อกำหนดชุดแล้วจึงปิดDEP-002 แต่ยังไม่ใช่การอนุมัติภาพใหม่ DEP-001ยังOPEN Ownerตรวจหัว ร่าง ชุดและมุมใหม่จากไฟล์จริง จากนั้นจึงบันทึกapprovalผูกhashก่อนactive ภาพที่ถูกปฏิเสธคงสถานะREJECTED
