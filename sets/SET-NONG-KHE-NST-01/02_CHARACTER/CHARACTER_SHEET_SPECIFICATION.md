# CHARACTER SHEET SPECIFICATION — น้องเข้ นสต. v0.3.0

## Views and expressions
สร้าง candidate หนึ่งแผ่น มีตัวหลักยืนสามส่วนเต็มตัวขนาดใหญ่ และ turnaround หน้า/ข้าง/หลังสูงเท่ากัน อีกสี่สีหน้าเก๊ก เขิน ตกใจ เหนื่อย หัวเหมือนกันทุกมุม ด้านหลังเห็นคอหัวจระเข้ต่อร่างคน ไม่มีหาง ให้ความสำคัญ anatomy ก่อนทำมุกฉาก

## Consistency criteria
เปรียบปากยาวกว้าง ตาอำพัน เปลือกตาหนา มุมยิ้มและแนวเกล็ดกับ REF01 ในขนาดเต็มและย่อ เลือกมุมหน้าเป็นมาตรวัดหนึ่งเดียว ห้ามต้นแบบแต่ละ view เป็นคนละกะโหลก มือคนข้างละห้านิ้ว เสื้อและรองเท้าตรงกันทุก view

## Composition
พื้นเทาอ่อนเรียบ ภาพหลักซ้ายประมาณ 40% แผ่น turnaround สามมุมด้านขวาบน สีหน้าอยู่ล่าง เว้นช่องชัด ไม่มีกรอบ master 4x2 เพราะนี่คือ Character Sheet ไม่ใช่ production sheet ใช้ชื่อเล็ก CHARACTER CANDIDATE ไม่ใช้คำว่า APPROVED จนมี receipt

## Approval scope
เจ้าของตรวจหัว สัดส่วน สไตล์ และรายละเอียดชุดแยกกัน DEP-001 ต้องอนุมัติไฟล์จริงที่มี hash; DEP-002 ต้องตกลงความถูกต้องเครื่องหมายก่อนเป็น CHARACTER_SHEET_ACTIVE บันทึกข้อแก้ไขพร้อมภาพใหม่ ไม่ถือคำสั่งสร้างภาพเป็นคำอนุมัติผล
