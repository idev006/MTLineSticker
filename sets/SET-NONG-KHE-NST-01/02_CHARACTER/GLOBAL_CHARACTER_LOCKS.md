# GLOBAL CHARACTER LOCKS — น้องเข้ นสต. v0.3.0

## Lock registry
- L01 หัวจระเข้ยาวกว้างมน สัดส่วนปากและตำแหน่งตาอ้าง REF01 ไม่เปลี่ยนเป็นไดโนเสาร์หัวสั้น
- L02 เกล็ดเทาเขียว ผิวใต้คางอ่อน ดวงตาอำพัน เปลือกตาหนา ยิ้มมุมปาก ไม่โชว์เขี้ยวขู่
- L03 ร่างชายวัยหนุ่มผู้ใหญ่ มือและเท้าเป็นคน ไม่มีหาง ไม่มีอุ้งมือสัตว์
- L04 ชุดนักเรียนนายสิบตำรวจระหว่างศึกษาเป็นชุดหลักทุกภาพ; รายละเอียดเครื่องหมายรอ DEP-002 ไม่เพิ่มดาวยศ
- L05 สไตล์ 3D กึ่งสมจริง แสงสตูดิโอนุ่ม เงาบนตัวสั้น รายละเอียดเกล็ดไม่กลบอารมณ์
- L06 หนึ่งภาพหนึ่ง intent; ตัวหลักเด่นกว่า caption/prop/เพื่อน ไม่มีฉากร้านและโลโก้
- L07 ทุก view ใช้กะโหลก ตา จมูก ปาก สัดส่วนร่างคนและชุดเดียวกัน; อารมณ์เปลี่ยนได้แต่ห้ามเปลี่ยนอัตลักษณ์

## Reference authority
REF01 PRIMARY_IDENTITY: เจ้าของกำหนดตัวการ์ตูนนี้เป็นนายแบบทั้งชุด ภาพบนควบคุมรูปร่างหัว ส่วนภาพล่างช่วยศึกษาตาปรือและความเหนื่อย ไม่ให้อำนาจเสื้อในมีมควบคุมเครื่องแบบ ข้อกำหนดชุดนักเรียนจาก OWNER-02/03 มีอำนาจเหนือเสื้อขาวต้นฉบับ

## Exceptions
อนุญาตยืดสีหน้าตาม expression รายภาพ ภายในรูปหัวและ L01/L02 เดิม เพื่อนประกอบแสดงเพียงแขน/ไหล่หรือหัวด้านข้างขนาดรองและร่างคนชุดนักเรียน ไม่เพิ่มคู่คาแรกเตอร์ประจำโดยไม่ได้อนุมัติ การเปลี่ยนชุดหรือสัดส่วนหลักต้องกลับเจ้าของตรวจและออก revision
