# GLOBAL_CHARACTER_LOCKS — น้องเข้ นสต. v0.5.0

## Lock registry
- L01 ใช้รูปหัวจากภาพบน REF01 เป็นหลัก กะโหลกแบนกว้าง ปากยาวมน ตาสูง เปลือกตาหนา ไม่ออกแบบเป็นจระเข้ตัวใหม่
- L02 เกล็ดเทาเขียว คางอ่อน ตาอำพันหม่น รอยยิ้มมุมปาก หน้านิ่งกวนตามต้นฉบับ ไม่เพิ่มแผล
- L03 ร่างคนชายผู้ใหญ่ ไหล่กว้าง สัดส่วนใกล้ REF01 ไม่หัวโตตัวเล็ก มือเท้าคน ไม่มีหาง
- L04 เสื้อเชิ้ตขาวแขนยาว ติดกระดุมทุกเม็ดรวมคอ เนกไทน้ำเงินเข้ม กางเกงขายาวสี สนว.01 เข็มขัดดำ เสื้อสอดในกางเกง ไม่เพิ่มยศหรือตราที่ไม่สั่ง
- L05 ภาพตัดต่อกึ่งสมจริงใกล้ REF01 ไม่ใช้รูปแบบการ์ตูน3Dจากcandidateที่ถูกปฏิเสธ
- L06 ตัวหลักหนึ่งตัวเด่น ไม่มีฉากร้าน โลโก้ คนเดินผ่านหรือcaptionในมีมบนCharacterSheet
- L07 ทุกมุมใช้หัว ร่าง และชุดเดียวกัน ภาพมุมใหม่ที่อนุมานต้องไม่แก้identityของมุมที่เห็นในต้นฉบับ

## Reference authority
REF01 เป็น PRIMARY IDENTITY/STYLE/POSE/WARDROBE ตาม OWNER-03 และ OWNER-05 โดยคำสั่งเนกไทน้ำเงินเข้มมีอำนาจเหนือสีที่เห็นในภาพ เจ้าของปฏิเสธcandidateเดิมตามOWNER-04 ห้ามเอามาเป็นแม่แบบอีก

## Exceptions
รอบนี้เน้นหัว สัดส่วน และชุด ไม่แตกสีหน้าใหม่ 4 แบบก่อนล็อกidentity รองเท้าดำเรียบเป็นส่วนอนุมานรอreview ไม่มีข้อยกเว้นให้ใส่เครื่องหมายเพิ่มหรือเปิดคอเสื้อ

## Trouser color lock
OWNER-07 ล็อกรหัสสี สนว.01 ทุกมุมของตัวละคร แทนกากีทั่วไปที่เคยเสนอ ห้ามเปลี่ยนเป็นสีเบจอ่อนแบบภาพก่อนหน้า เฉดบนหน้าจอเป็นภาพจำลองรอเจ้าของตรวจเทียบกับผ้าจริง ยังไม่มีค่า sRGB/Lab ที่ยืนยัน จึงไม่แต่งรหัส HEX ว่าเป็นมาตรฐาน
