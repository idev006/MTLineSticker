# NEGATIVE CONSTRAINTS — น้องเข้ นสต. v0.5.0

## Forbidden changes
ไม่ตัดหัวให้ปากสั้น ไม่เพิ่มหาง ผิวมือเกล็ด นิ้วสัตว์ เขี้ยวใหญ่ หรือเด็กจระเข้ ไม่เอาชุดขาวไทดำตามมีมมาใช้ ไม่สร้างตราหรือยศที่อ้างความเป็นตำรวจสำเร็จการศึกษา ไม่เปลี่ยนโทนผิวหรือสัดส่วนร่างคนข้ามภาพ

## Reference exclusions
ตัดอำนาจอ้างอิงร้านสะดวกซื้อ โลโก้ ป้ายโฆษณา คนเดินผ่าน caption เพื่อน/ผม จักรยาน/อุปกรณ์สวน และแผลในภาพล่าง ทั้งหมดไม่ใช่ส่วนอัตลักษณ์นายแบบและไม่ต้องปรากฏในชุดใหม่

## Rendering defects
ปฏิเสธมือเกินนิ้ว เสื้อสองชุดในคนเดียว ปากแยกจากหัว คอต่อผิดธรรมชาติ ขา/รองเท้าหลุดเฟรม เงาพื้นยาวจนแยกตัดไม่ได้ และแผ่น turnaround ที่หน้าตาไม่ตรงกัน อย่าใช้ checkerboard วาดแทนความโปร่งใสของ production
