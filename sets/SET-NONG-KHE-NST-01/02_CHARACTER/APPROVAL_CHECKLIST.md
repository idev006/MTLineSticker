# APPROVAL CHECKLIST — น้องเข้ นสต. v0.3.0

## Identity checks
ตรวจรูปปากยาวมน ตำแหน่งตาสูง เปลือกตาหนา เกล็ด และมุมยิ้มเทียบ REF01; ตรวจหน้า/ข้าง/หลังยังเป็นตัวเดียวกัน; ร่างคนไม่มีหาง นิ้วและเท้าคนถูกต้อง สัดส่วนต้องดูเป็นผู้ใหญ่ตามบรีฟ

## Wardrobe checks
เจ้าของตรวจว่าเป็นชุดนักเรียนนายสิบตำรวจที่ต้องการ ไม่ใช่ชุดนักศึกษาทั่วไปและไม่ใส่ยศสำเร็จการศึกษา DEP-002 ยัง OPEN จนมีภาพชุดจริงหรือคำกำหนดรายละเอียดจากเจ้าของ อินทรธนูเรียบเป็นแบบรอตรวจ ไม่อ้างว่าใช้แทนเครื่องหมายจริงได้

## Style checks
ตรวจ 3D กึ่งสมจริงใกล้มีม มีความกวน ไม่ขู่ สีหน้าแยกเก๊ก/เขิน/ตกใจ/เหนื่อยได้ในภาพย่อ ใบหน้าไม่มืด ผ้าและเกล็ดไม่แย่งสายตาจากอารมณ์ พื้นเรียบและทุกมุมไม่ถูก crop

## Approval evidence
ปัจจุบัน character=null ใน approvals.json จึงไม่ผ่าน DEP-001 หลังเจ้าของเห็นและอนุมัติภาพ ให้เก็บ exact file, SHA256, ข้อความอนุมัติ, decision ID และขอบเขต รวมทั้งผลตรวจเครื่องแบบก่อนเปิด CHARACTER_SHEET_ACTIVE การเปลี่ยนรูปภายหลังต้องอนุมัติใหม่
