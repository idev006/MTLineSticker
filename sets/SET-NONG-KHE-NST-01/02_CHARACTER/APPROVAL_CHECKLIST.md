# APPROVAL_CHECKLIST — น้องเข้ นสต. v0.5.0

## Identity checks
เทียบภาพหลักกับREF01โดยตรง: กะโหลกแบนกว้าง ปากยาวกว้าง เปลือกตาหนา รอยยิ้มมุมปาก เกล็ดและคอ ไม่เปลี่ยนเป็นจระเข้น่ารัก ตรวจสัดส่วนร่างคนไหล่กว้างและมือคน ไม่มีหางหรือหัวโต

## Wardrobe checks
เสื้อเชิ้ตสีขาวแขนยาว ติดกระดุมครบทุกเม็ดรวมเม็ดบนสุดที่คอ ผูกเนกไทสีน้ำเงินเข้ม กางเกงขายาวสี สนว.01 เข็มขัดสีดำ ตรวจปกปิดเม็ดคอ ไทน้ำเงินเข้มไม่ดำ เสื้อสอดกางเกงและไม่มีอินทรธนู/ตราเพิ่ม รองเท้าดำเป็นข้อเสนอรอreview เจ้าของยืนยันชุดแล้วในOWNER-05 ไม่กลับไปใช้เสื้อกากีแขนสั้น

## Style checks
ใกล้ภาพตัดต่อกึ่งสมจริงของREF01 ไม่ใช้ผิวและกะโหลก3Dจากภาพที่ถูกปฏิเสธ ตรวจมุมใหม่ว่าเป็นตัวเดิม มุมหลักกางแขนตรงต้นฉบับ พื้นเรียบและไม่มีภาพแทรกสีหน้าใหม่

## Approval evidence
