# SET-006 Production Spec v1.0

## Review sheet
- 4 sheets
- 10 stickers per sheet
- grid 2 rows × 5 columns
- logical master frame: 512×512 px
- review sheet logical size: 2560×1024 px
- transparent background
- black frame lines allowed **only for review sheet**
- frame number allowed **only for review sheet**
- artwork must not cross frame boundaries
- safe padding target: 20 px at 512 master scale

## Individual master
- one PNG per sticker
- transparent RGBA
- 512×512 master canvas (internal production master)
- no black square frame in final art
- no review number in final art

## LINE export
Before submission, export each sticker to a size compliant with current official LINE static-sticker guideline. Do not assume the platform spec is permanent; re-check on submission day.

Current working target for square compositions: **320×320 px PNG transparent**, subject to official max limits.

## Naming
- `SET006-001.png` … `SET006-040.png`
- `SET006-main.png`
- `SET006-tab.png`
- Review sheets: `SET006-sheet-01-review.png` etc.

## Typography
Final Thai text must be proofread 100%; text must remain legible after LINE export.

## Asset retention
Retain:
- master 512 PNG
- final LINE PNG
- review sheet
- approved hero refs
- QA report
