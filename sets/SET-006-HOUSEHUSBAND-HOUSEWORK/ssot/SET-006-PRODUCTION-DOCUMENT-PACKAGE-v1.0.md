## 1. Product concept

**Core concept:** ผู้ชายวัยผู้ใหญ่ลุคมีวินัย สุภาพ อบอุ่น พึ่งพาได้ ทำงานบ้านธรรมดาด้วยพลังแบบ “รับภารกิจ” อย่างจริงจังและมีอารมณ์ขันแบบ deadpan โดยไม่ใช้มุกลดศักดิ์ศรีหรือ “กลัวเมีย” เป็นแกน

**Product promise:** Reliable + Warm + Disciplined + Funny.

**USP:** **งานบ้านธรรมดา แต่รับภารกิจอย่างจริงจัง**

**Primary use context:** ใช้ในแชตกับคู่รัก ครอบครัว และคนใกล้ชิด เพื่อแจ้งว่ากำลังทำงานบ้าน อาสารับงาน แจ้งความคืบหน้า/เสร็จงาน และส่ง reaction หลังทำงานบ้าน

**Primary target:** ผู้ชายวัยทำงานประมาณ 28–45 ปีที่มีแฟน/คู่สมรส/ครอบครัวและต้องการ sticker ผู้ใหญ่ สุภาพ ใช้แทนตัวเองได้

**Secondary target:** คู่รัก/สมาชิกครอบครัวและผู้ใช้ทั่วไปที่ชอบ character ผู้ชายพึ่งพาได้

### Locked identity
- adult male, approximately 30–40
- clean-shaven
- very short police/military-inspired buzz cut; neat sharp front hairline
- athletic adult proportions; never childlike/chibi
- navy T-shirt default
- black shorts default
- vivid orange sneakers when visible
- black tactical watch on LEFT wrist
- black crossbody bag only when action/context allows
- sunglasses optional; expression readability has priority
- warm, reliable, disciplined behavior; humor from seriousness, not humiliation

### Approved contextual adaptations
- apron allowed for kitchen Frames
- crossbody bag may be removed for wet/cleaning work or when physically implausible
- props may change by household task

### Prohibited drift
- beard/moustache/stubble
- fluffy/spiky redesign of haircut
- childlike/chibi body proportions
- random age/face changes
- macho/aggressive treatment inconsistent with warm family role
- heavy environmental scene, poster or infographic treatment

## 7. Visual production rules

**Communication hierarchy:** Character face/expression → action/gesture → caption → required prop → optional accents.

**Camera:** choose the simplest angle that keeps face, action and essential prop readable. Full-body is allowed only when action needs it and face remains legible.

**Prop density:** normally 1 primary prop/group; 2–3 only where communication requires it. F038 is the controlled exception but must remain readable.

**Typography:** use exact locked caption. AI-rendered Thai is candidate-level until verified; reserve composition space for deterministic typography when needed.

**Background:** transparent-final intent; do not build environmental scenes. Minimal contextual cue is allowed only when it accelerates meaning.

**Visual variety:** adjacent Frames should vary pose/camera/action sufficiently to avoid repetitive set rhythm while preserving Character identity.
