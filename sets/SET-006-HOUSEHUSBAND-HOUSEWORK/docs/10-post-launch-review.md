# 10 — Post-Launch Review

## Review cadence
- T+7 days: early signal
- T+30 days: initial product review
- T+90 days: retrospective / next-set decision

## Questions
1. ผู้ใช้ชอบ caption กลุ่มใดมากที่สุด?
2. งานบ้านประเภทใดมี reaction/feedback สูง?
3. Main image สื่อ character ได้ชัดหรือไม่?
4. มีคำที่ผู้ใช้ขอเพิ่มซ้ำ ๆ หรือไม่?
5. มี pose/props ใดที่คนจำได้เป็น signature?
6. ชุดถัดไปควรแตกธีมไปทาง “พ่อกับลูก”, “ภารกิจเมียสั่ง”, หรือ “วันหยุด” หรือไม่?

## Learning log fields
- Date
- Evidence/source
- Observation
- Hypothesis
- Recommended change
- Apply to this set / next set / framework

## Change rule
ผลหลัง launch ไม่แก้ไฟล์ย้อนหลังแบบไร้ version; ต้องบันทึกเป็น revision หรือใช้เป็น input ชุดถัดไป
