# 02 — Goals, Objectives & KPI

## North-star goal
พัฒนาสติ๊กเกอร์ LINE ชุด “พ่อบ้านสายงานบ้าน” ให้เป็นสินค้าดิจิทัลคุณภาพสูง ใช้งานได้จริง มีเอกลักษณ์ทางการตลาด และพร้อมขายใน LINE Creators Market โดยใช้ CPDF เป็นระบบควบคุมคุณภาพและการเรียนรู้

## Objectives
### O1 — Product quality
สร้าง 40 ภาพที่ดูเป็นคาแรกเตอร์คนเดียวกัน อ่านง่าย และมี visual variety เพียงพอ

### O2 — Conversation utility
อย่างน้อย 80% ของ caption ต้องมีสถานการณ์ใช้งานในชีวิตประจำวันชัดเจน

### O3 — Brand differentiation
ทุกภาพต้องคง signature อย่างน้อย 2 ใน 4 เสา: **Reliable / Warm / Disciplined / Funny**

### O4 — Platform readiness
Final asset ต้องผ่าน technical checklist 100% ก่อน submission

### O5 — Commercial learning
หลังเปิดขาย ต้องเก็บข้อมูลและ feedback เพื่อปรับชุดถัดไป

## Pre-launch KPI / Acceptance Metrics
- Character consistency pass: 40/40
- Caption correctness: 40/40
- Transparent PNG pass: 40/40
- Technical export pass: 40/40
- Duplicate/near-duplicate composition: ไม่เกิน 10% ของชุด
- Hero Set approval: 6/6 ผ่านก่อน full production
- QA blocker unresolved: 0
- Secondary-character continuity issues: 0 blocker

## Post-launch KPI (tracking, not guaranteed outcome)
- Store approval status
- Sales/download trend by week
- Revenue trend
- User feedback themes
- Most-mentioned / most-liked captions
- Conversion impact of main image and title revisions (ถ้ามีข้อมูล)

> หมายเหตุ: KPI ด้านยอดขายเป็นตัววัดผล ไม่ใช่การรับประกันความสำเร็จเชิงพาณิชย์
