# 03 — Market Positioning

## Target segments
### Primary
ผู้ชายวัยทำงานประมาณ 28–45 ปี มีแฟน/คู่สมรส/ครอบครัว ต้องการสติ๊กเกอร์ที่ดูเป็นผู้ใหญ่ แมน สุภาพ และใช้แทนตัวเองได้

### Secondary
ภรรยา/แฟน/สมาชิกครอบครัวที่ชอบคาแรกเตอร์ผู้ชายพึ่งพาได้และอยากส่งมุกงานบ้านแบบอบอุ่น

### Tertiary
คนทำงานทั่วไปที่ใช้ข้อความแนว “เดี๋ยวทำเอง / เรียบร้อยแล้ว / กำลังจัดการ” ได้ทั้งในบ้านและแชตไม่เป็นทางการ

## Positioning statement
สำหรับผู้ใช้ที่ต้องการสติ๊กเกอร์ผู้ชายสำหรับเรื่องงานบ้าน “พ่อบ้านสายงานบ้าน” คือชุดสติ๊กเกอร์ที่ผสม **ความมีวินัย + ความอบอุ่น + งานบ้านจริง + deadpan mission comedy** ต่างจากสติ๊กเกอร์ “กลัวเมีย” ที่ขายการยอมจำนน เพราะตัวละครของเรายอมช่วยด้วยความรักและความรับผิดชอบ

## Unique Selling Proposition
**“งานบ้านธรรมดา แต่รับภารกิจอย่างจริงจัง”**

## Signature system
- Military/police-inspired clean haircut
- Navy + black base palette
- Bright orange shoes เป็น visual accent
- Left-wrist tactical watch
- Black crossbody bag when context allows
- Strong readable gesture
- Short polite Thai captions
- Humor from seriousness, not humiliation

## Brand pillars
- Reliable
- Warm
- Disciplined
- Funny

## Market risks
- ถ้าพร็อพเยอะเกิน จะดูรกและอ่านยาก
- ถ้าทุกภาพเป็น “งานบ้านเฉย ๆ” จะขาดมุกและ personality
- ถ้าทุก caption ลงท้ายเหมือนกันเกิน จะรู้สึกซ้ำ
- ถ้าใช้ secondary characters โดยไม่คุม จะทำให้ IP consistency ลดลง

## Mitigation
ใช้ Production Architecture 4 หมวด + Hero Gate + visual-variety review + caption-utility review ก่อนผลิตเต็มชุด
