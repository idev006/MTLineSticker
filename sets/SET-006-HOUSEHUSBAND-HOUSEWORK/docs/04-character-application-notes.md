# 04 — Character Application Notes

## Inherited Character SSOT
SET-006 ใช้คาแรกเตอร์เดียวกับ “พ่อบ้านสายวินัย” โดยไม่แก้ identity หลัก

## Hard locks
- ไม่มีหนวด / เครา / เงาเครา
- ผมสั้นเกรียนแบบตำรวจ/ทหาร ด้านข้างและด้านหลังสั้นมาก
- Hairline ด้านหน้าคม เนี้ยบ
- รูปร่าง fit/athletic ไม่ bodybuilder เกินจริง
- เสื้อยืดกรมท่าเป็น default
- กางเกงขาสั้นดำเป็น default ของชุดนี้
- รองเท้าส้มสดเป็น signature accent
- นาฬิกาดำข้อมือซ้าย
- กระเป๋าสะพายข้างดำ: default-on เมื่อไม่รบกวนงานบ้าน
- แว่นดำ: optional, ใช้เพื่อมุก/ลุค ไม่ใช้ในภาพที่ต้องอ่าน expression ชัด

## Housework adaptation rules
- ในงานครัวสามารถเพิ่ม apron ได้
- ในงานเปียก/ทำความสะอาดสามารถถอด crossbody bag ถ้าไม่สมเหตุผล
- รองเท้าอาจยังคงเพื่อ signature แต่ต้องไม่ทำให้สถานการณ์ดูอันตรายหรือขัดธรรมชาติอย่างชัดเจน
- Props ต้องช่วย “อ่านงานบ้าน” ไม่ใช่โชว์ของเยอะ

## Secondary characters
- ภรรยา/ลูกไม่ใช่ตัวเอก
- ถ้าปรากฏมากกว่า 2 เฟรม ให้สร้าง mini-reference sheet ก่อน full production
- ห้ามเปลี่ยนอายุ/ผม/สัดส่วนแบบสุ่มระหว่างเฟรม

## Character behavior
- ขยัน
- ไม่บ่นแรง
- มีเหนื่อยได้
- มี deadpan reaction ได้
- ไม่ดูถูกงานบ้าน
- ไม่ใช้มุก “ภรรยากดขี่” เป็นแกน
