# 05 — Visual Style Application

## Base style
**Soft Painterly Semi-Anime + Clean Sticker Finish**

## Rendering rules
- clean linework / edge clarity
- soft painterly shading แบบควบคุม ไม่ฟุ้งจนอ่านยาก
- face readable at thumbnail size
- white sticker cutline รอบตัวละครและข้อความ
- transparent background
- props simplified but recognizable
- orange accent ใช้ช่วยนำสายตา

## Typography
- Thai bold rounded / highly legible
- short phrase preferred
- navy / orange / accent colors ใช้สม่ำเสมอ
- outline ขาว/เข้มเพื่ออ่านได้บนทุกพื้นหลัง
- ห้ามพึ่ง AI text เป็น final โดยไม่ตรวจ spelling 100%

## Composition
- Subject + caption ต้องอยู่ใน safe area
- อย่าตัดศีรษะ มือ หรือ prop สำคัญ
- ระยะหายใจรอบ artwork อย่างน้อยตาม Production Spec
- เมื่อเป็น review sheet: artwork ห้ามล้ำข้าม frame

## Visual variety
ภายใน 10 ภาพติดกันต้องพยายามไม่ใช้:
- มุมกล้องเดียวกันเกิน 3 ภาพ
- thumbs-up ซ้ำเกิน 2 ภาพ
- กอดหมอน/นอนซ้ำเกิน 2 ภาพ
- props ประเภทเดียวกันติดกันหลายเฟรม

## Do
- dynamic but readable poses
- clear household storytelling
- warm face / responsible energy
- use orange shoes as recognizability anchor

## Don't
- photorealism
- chibi proportion
- messy sketch style
- heavy scene background
- tiny full-body composition that loses facial readability
