# 05 — Visual Style Application

**Version:** 1.1

## Base style
**Soft Painterly Semi-Anime + Clean Sticker Finish**

## Core principle
SET-006 artwork is a **LINE communication asset**, not a standalone illustration. Every frame starts from an approved caption/use case, then designs expression, gesture/action and only the minimum useful prop to communicate that intent immediately.

Reference standards:
- `docs/project/CHARACTER_PRODUCT_DEVELOPMENT_FRAMEWORK.md`
- `docs/standards/STICKER_COMMUNICATION_STANDARD.md`

## Mandatory Character Reference
Use the approved “พ่อบ้านสายวินัย” Character Sheet as the active visual reference for every generation/revision pass.

Locked traits:
- adult male, approximately 30–40
- clean-shaven
- very short police/military-inspired haircut with neat sharp hairline
- athletic adult proportions; **not chibi**
- navy T-shirt
- black shorts
- vivid orange shoes when visible
- black tactical watch on LEFT wrist
- black crossbody bag only when it does not interfere with the action
- sunglasses optional; facial readability has priority

Any candidate that redesigns the character away from this reference is REJECTED, even if the image is attractive.

## H01 Golden Reference
The owner-approved H01 “ล้างจานอยู่ครับ” is the rendering/communication Golden Reference for this set.

Use it to anchor:
- adult face and proportion language,
- controlled painterly rendering,
- caption-to-character hierarchy,
- prop simplification,
- white sticker cutline treatment,
- communication-first framing.

The Golden Reference **does not replace** the Character Sheet. Both references must agree.

## Communication design rule
For every sticker define before generation:
1. exact caption
2. sender intent
3. likely chat situation
4. emotion/tone
5. primary facial expression
6. primary gesture/action
7. minimum required prop
8. forbidden distractions

The pose/action should communicate the meaning before the caption is fully read. The candidate must pass the **1-second test** at chat-preview scale.

## Rendering rules
- clean edge clarity
- controlled soft painterly shading
- face readable at thumbnail/chat size
- white sticker cutline around foreground character/text when appropriate
- transparent final background
- props simplified but recognizable
- orange accent may reinforce recognizability
- foreground hierarchy must remain clear after reduction

## Typography
- Thai bold rounded / highly legible
- short phrase preferred
- navy / orange / controlled accents
- outline when needed for readability
- AI-generated Thai text is never final until spelling is deterministically verified 100%
- if exact text cannot be reliably generated, apply final typography using a controlled text layer

## Composition
- subject + caption inside safe area
- do not crop head, hands, gesture or required prop
- avoid tiny full-body treatment when it weakens facial readability
- avoid poster, infographic, cinematic scene or environmental illustration layouts
- avoid scene depth that makes the sticker look like a poster rather than a chat asset
- review-sheet artwork must not cross frame boundaries

## Production format discipline
Hero and production candidates should be generated/reviewed as **standalone individual stickers**. Multi-panel sheets are for review only after individual assets are accepted.

## Visual variety
Within 10 adjacent stickers, avoid repetitive camera/pose/prop solutions. Do not use the same gesture as the default solution for unrelated meanings.

## Do
- communication-first pose
- clear household action
- warm, reliable adult personality
- disciplined mission energy applied humorously to ordinary chores
- preserve the approved adult face/hair/body identity
- keep only props that accelerate comprehension

## Don't
- photorealism
- chibi proportions
- fluffy/spiky anime redesign of the haircut
- childlike face/body proportions
- heavy scene background
- decorative props that compete with the message
- infographic/poster layouts
- generate artwork first and attach a caption afterward
- use a combined AI sheet as the final source for individual sticker exports
