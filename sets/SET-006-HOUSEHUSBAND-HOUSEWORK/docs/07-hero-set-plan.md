# 07 — Hero Set Plan

## Objective
ทดสอบว่า “พ่อบ้านสายงานบ้าน” สื่อสารได้จริงในแชต มี identity ชัด และแยกจากชุดแรกได้ ก่อนผลิตครบ 40 ภาพ

Hero ไม่ได้มีหน้าที่แค่ทดสอบความสวย แต่ต้องพิสูจน์ 4 เรื่องพร้อมกัน:
1. Character fidelity
2. Communication clarity
3. Caption-image fit
4. Production/LINE readiness

## Mandatory preflight for every Hero
ก่อนสร้างภาพ ต้องล็อก:
- exact caption
- sender intent
- likely chat situation
- facial expression
- primary gesture/action
- minimum required prop
- active approved Character Sheet reference
- forbidden drift: chibi, fluffy/spiky hair redesign, childlike proportions, poster/infographic/scene treatment

## Hero 6
1. **H01 / #01 — ล้างจานอยู่ครับ**  
   Intent: แจ้งว่ากำลังล้างจาน/กำลังจัดการงานครัวอยู่  
   Visual cue: กำลังล้างจานจริง มือ/จาน/ฟองน้ำอ่านง่าย ตัวละครยังเด่นกว่าฉาก

2. **H02 / #05 — กำลังถูพื้นครับ**  
   Intent: แจ้งว่ากำลังทำความสะอาดพื้น  
   Visual cue: action ของไม้ถูพื้นชัด + full/three-quarter body ที่ยังอ่านสีหน้าได้ + รองเท้าส้มเมื่อเห็น

3. **H03 / #15 — พับผ้าอยู่ครับ**  
   Intent: แจ้งว่ากำลังพับ/จัดผ้า  
   Visual cue: มือกำลังพับผ้า + กองผ้าเท่าที่จำเป็น ไม่ทำเป็นฉากซักรีดเต็มเฟรม

4. **H04 / #21 — ทำกับข้าวอยู่ครับ**  
   Intent: แจ้งว่ากำลังทำอาหาร  
   Visual cue: action ทำอาหารชัด ใช้ apron ได้โดยไม่ทำลาย Character identity; ฉากครัวต้องไม่แย่งตัวละคร

5. **H05 / #31 — กำลังจัดบ้านครับ**  
   Intent: แจ้งว่ากำลังจัดของ/จัดบ้าน  
   Visual cue: กล่องหรือของจัดเก็บจำนวนน้อยแต่สื่อความหมายทันที

6. **H06 / #40 — พ่อบ้านพร้อมลุยงานบ้านครับ!**  
   Intent: พร้อมรับภารกิจงานบ้าน / ใช้เป็น closing hero  
   Visual cue: confident mission-ready pose ที่ยังอบอุ่น ไม่ macho เกิน และไม่ใช่ thumbs-up generic เพียงอย่างเดียว

## Hero Fit Gate — Pass criteria
- 6/6 ดูเป็นผู้ชายคนเดียวกับ Approved Character Sheet
- adult semi-anime proportions; zero chibi drift
- haircut / face / navy shirt / black shorts / orange shoes / left-wrist watch consistent where visible
- ทุกภาพมี use case ในแชตชัด
- ภาพช่วยสื่อ caption ก่อนอ่านข้อความ
- caption ถูกต้องและอ่านง่ายทุกภาพ
- props ไม่บดบัง expression/gesture
- housework meaning อ่านได้เร็ว
- transparent production-ready master
- ลดขนาดแล้ว expression + action + caption ยังอ่านได้
- ทั้ง 6 ภาพดูเป็นสินค้า commercial set เดียวกัน

## Corrective rule
ถ้า Hero แรกมี Character drift ห้ามผลิต Hero ที่เหลือต่อเป็น batch ให้หยุดและแก้ H01 จน Character Fit ผ่านก่อน เพื่อไม่ขยาย defect ไปทั้งชุด

## Outcome
- PASS → unlock 40 production
- PASS WITH CORRECTIONS → fix Hero then re-audit
- FAIL → revisit Character/Style/Communication brief before continuing
