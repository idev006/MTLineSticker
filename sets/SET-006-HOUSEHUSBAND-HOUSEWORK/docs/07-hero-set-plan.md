## Hero Fit Gate — Pass criteria
- 6/6 ดูเป็นคนเดียวกัน
- orange shoes / haircut / body / face consistent
- caption อ่านง่ายทุกภาพ
- props ไม่บดบัง gesture
- housework theme อ่านได้ใน 1 วินาที
- visual style ต่างจาก generic housework sticker ด้วย disciplined mission energy
- transparent production-ready master

## Outcome
- PASS → unlock 40 production
- PASS WITH CORRECTIONS → fix hero then re-audit
- FAIL → revisit Style/Character application before continuing
