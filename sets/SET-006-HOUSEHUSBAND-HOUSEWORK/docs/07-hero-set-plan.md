# 07 — Hero Set Plan

**Version:** 1.1  
**Status:** H01 approved; sequential corrective Hero production active.

## Objective
ทดสอบว่า “พ่อบ้านสายงานบ้าน” สื่อสารได้จริงในแชต มี identity ชัด และแยกจากชุดแรกได้ ก่อนผลิตครบ 40 ภาพ

Hero ไม่ได้มีหน้าที่แค่ทดสอบความสวย แต่ต้องพิสูจน์ 5 เรื่องพร้อมกัน:
1. Character fidelity
2. Communication clarity
3. Caption-image fit
4. Small-size readability
5. Production/LINE readiness

## Mandatory preflight for every Hero
ก่อนสร้างภาพ ต้องล็อก:
- exact caption
- sender intent
- likely chat situation
- emotion/tone
- facial expression
- primary gesture/action
- minimum required prop
- active approved Character Sheet reference
- H01 Golden Reference
- forbidden drift: chibi, fluffy/spiky hair redesign, childlike proportions, poster/infographic/scene treatment

## Golden Reference
**H01 / #01 — ล้างจานอยู่ครับ** ได้รับ owner approval แล้ว และเป็น Golden Reference สำหรับการผลิต H02–H06

Golden Reference ใช้ล็อก rendering feel, adult identity, caption hierarchy และระดับความเรียบง่ายขององค์ประกอบ แต่ Character Sheet ยังคงเป็น SSOT ด้านรูปลักษณ์ตัวละคร

## Hero 6
1. **H01 / #01 — ล้างจานอยู่ครับ — PASS**  
   Intent: แจ้งว่ากำลังล้างจาน/กำลังจัดการงานครัวอยู่  
   Visual cue: กำลังล้างจานจริง มือ/จาน/ฟองน้ำอ่านง่าย ตัวละครเด่นกว่าฉาก

2. **H02 / #05 — กำลังถูพื้นครับ — NEXT**  
   Intent: แจ้งว่ากำลังทำความสะอาดพื้น  
   Chat use: ส่งบอกคู่รัก/ครอบครัวว่ากำลังทำงานบ้านนี้อยู่  
   Visual cue: action ไม้ถูพื้นชัด, 3/4 หรือ full-body ที่ยังอ่านสีหน้าได้, รองเท้าส้มเมื่อเห็น  
   Limit: ไม้ถูพื้น + ถัง/หยดน้ำเท่าที่จำเป็น; ห้ามทำเป็นฉากห้องเต็มเฟรม

3. **H03 / #15 — พับผ้าอยู่ครับ**  
   Intent: แจ้งว่ากำลังพับ/จัดผ้า  
   Visual cue: มือกำลังพับผ้า + กองผ้าเท่าที่จำเป็น ไม่ทำเป็นฉากซักรีดเต็มเฟรม

4. **H04 / #21 — ทำกับข้าวอยู่ครับ**  
   Intent: แจ้งว่ากำลังทำอาหาร  
   Visual cue: action ทำอาหารชัด ใช้ apron ได้โดยไม่ทำลาย Character identity; ครัวต้องไม่แย่งตัวละคร

5. **H05 / #31 — กำลังจัดบ้านครับ**  
   Intent: แจ้งว่ากำลังจัดของ/จัดบ้าน  
   Visual cue: กล่องหรือของจัดเก็บจำนวนน้อยแต่สื่อความหมายทันที

6. **H06 / #40 — พ่อบ้านพร้อมลุยงานบ้านครับ!**  
   Intent: พร้อมรับภารกิจงานบ้าน / ใช้เป็น closing hero  
   Visual cue: confident mission-ready pose ที่อบอุ่น ไม่ macho เกิน และไม่ใช่ thumbs-up generic เพียงอย่างเดียว

## Sequential production rule
หลัง H01 ผ่านแล้ว ให้ผลิต **ทีละ Hero แบบ standalone master** ตามลำดับ H02 → H03 → H04 → H05 → H06

สำหรับแต่ละภาพ:
1. generate standalone candidate
2. Character Fit QA
3. Communication Fit + 1-second test
4. Caption/Typography QA
5. small-size/composition QA
6. transparency/technical QA
7. accept/correct before moving to next Hero

ห้ามใช้ combined six-Hero sheet เป็นหลักฐานแทนการตรวจรายภาพ

## Hero Fit Gate — Pass criteria
- H01–H06 เป็น individual accepted masters ครบ
- 6/6 ดูเป็นผู้ชายคนเดียวกับ Approved Character Sheet
- adult semi-anime proportions; zero chibi drift
- haircut / face / navy shirt / black shorts / orange shoes / left-wrist watch consistent where visible
- ทุกภาพมี chat use case ชัด
- ทุกภาพผ่าน 1-second communication test
- caption ถูกต้องและอ่านง่าย
- props ไม่บดบัง expression/gesture
- housework meaning อ่านได้เร็ว
- real transparent production-ready master
- ลดขนาดแล้ว expression + action + caption ยังอ่านได้
- ทั้ง 6 ภาพดูเป็นสินค้า commercial set เดียวกัน

## Review sheet rule
หลัง Hero ทั้ง 6 ผ่านรายภาพแล้ว จึงประกอบ Hero review sheet แบบ deterministic จากไฟล์ที่ผ่าน เพื่อดู consistency รวมทั้งชุด

## Outcome
- PASS → unlock 40 production
- PASS WITH CORRECTIONS → fix failed Hero only then re-audit
- FAIL → revisit Character/Style/Communication brief before continuing
