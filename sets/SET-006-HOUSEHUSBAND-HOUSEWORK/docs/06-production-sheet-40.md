## Caption rules
- ภาษาไทยต้องตรวจ 100%
- หลีกเลี่ยงประโยคยาวเกินความจำเป็น
- แต่ละ caption ต้องมี use case แยกกันชัดพอ
- final copy อาจปรับคำเล็กน้อยหลัง user validation แต่ต้อง update SSOT/version

## Visual-density rule
Props ต่อเฟรมควรมี **1–3 กลุ่มวัตถุหลัก** เท่านั้น เว้นแต่เป็น reaction ที่ตั้งใจให้ “งานล้น”
