# 01 — Project Brief

## 1. ชื่อผลิตภัณฑ์
**พ่อบ้านสายงานบ้าน**  
Working English title: **Disciplined Househusband: Home Duty**

## 2. Product statement
LINE Sticker ชุดเต็ม 40 ภาพ สำหรับคนที่ต้องการสื่อสารเรื่อง “งานบ้านและความรับผิดชอบในครอบครัว” ด้วยคาแรกเตอร์ผู้ชายลุคมีวินัย สุภาพ อบอุ่น และตลกจากการทำเรื่องบ้าน ๆ อย่างจริงจัง

## 3. Problem / Opportunity
ตลาดสติ๊กเกอร์ครอบครัวมีทั้งแนวน่ารัก กลัวเมีย และงานบ้านทั่วไป แต่ยังมีพื้นที่สำหรับคาแรกเตอร์ผู้ชายที่ “ดูมีวินัย พึ่งพาได้ และเต็มใจทำงานบ้าน” โดยไม่ลดศักดิ์ศรีตัวละคร ซึ่งตอบโจทย์ผู้ชายวัยทำงาน คู่สมรส และครอบครัวที่ต้องการสติ๊กเกอร์ใช้จริงในชีวิตประจำวัน

## 4. Jobs-to-be-Done
ผู้ใช้ “จ้าง” สติ๊กเกอร์ชุดนี้เพื่อ:
- แจ้งว่ากำลังทำงานบ้านอยู่
- รับงาน / อาสาทำ / บอกว่าจะจัดการให้
- แจ้งว่างานเสร็จแล้ว
- สื่อความรับผิดชอบต่อครอบครัวแบบอบอุ่น
- เล่นมุกกับคู่รักโดยไม่ดูถูกฝ่ายใด
- ส่งข้อความแทนตัวเองด้วยภาพที่ดูแมน สุภาพ และน่ารัก

## 5. Scope
### In scope
- Static sticker 40 ภาพ
- Main image 1 ภาพ
- Tab icon 1 ภาพ
- Product title / description / store copy
- Hero prototype set 6 ภาพ
- Review sheets 4 แผ่น × 10 เฟรม
- Final PNG 40 ไฟล์

### Out of scope
- Animated sticker
- Emoji
- Merchandise
- New family-character SSOT เต็มรูปแบบ (เว้นแต่ secondary character ถูกใช้ซ้ำหลายภาพ)

## 6. Product principles
1. ใช้ได้จริงในการสนทนา
2. งานบ้านต้องเป็น “ภารกิจ” ที่เล่าเรื่องได้ทันที
3. ตัวละครต้องดูพึ่งพาได้ ไม่ใช่ถูกกดขี่
4. Caption สั้น อ่านเร็ว
5. Character consistency สูง
6. Production ต้องรองรับ automated slicing/export
7. Final asset ต้องผ่าน LINE compliance
