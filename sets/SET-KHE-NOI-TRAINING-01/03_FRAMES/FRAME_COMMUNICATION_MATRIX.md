# FRAME_COMMUNICATION_MATRIX — เข้น้อย อยู่ระหว่างฝึก

## Shared locks
L01 หัวจระเข้ตามCHAR04เดิม กะโหลกแบนกว้าง ปากยาวมน ตาสูง เปลือกตาหนา ไม่ออกแบบหัวใหม่
L02 เกล็ดเทาเขียว คางอ่อน ตาอำพันหม่น รอยยิ้มมุมปาก ไม่มีรอยแผล สีหน้าเปลี่ยนโดยไม่เปลี่ยนกะโหลก
L03 ร่างคนชายผู้ใหญ่ ไหล่กว้าง มือคน ไม่มีหาง ไม่ทำหัวโตตัวเล็ก
L04 เสื้อขาวแขนยาวติดกระดุมครบรวมเม็ดคอ เนกไทน้ำเงินเข้ม กางเกงสนว.01 เข็มขัดดำ ไม่มีตรา/ยศสมมติ
L05 ผิวและสไตล์ภาพกึ่งสมจริงตามCHAR04 ไม่เปลี่ยนเป็นมาสคอต3Dน่ารัก
L06 หนึ่งภาพหนึ่งintent พื้นหลังโปร่งใส ไม่มีฉากใหญ่หรือคนอื่นแย่งหน้า
L07 ครึ่งตัวบนเป็นหลัก cropที่เอว/อกโดยเก็บหัวครบ มือสำคัญไม่หลุด; ไม่เพิ่มเต็มตัวเพื่อแสดงขาที่ไม่ช่วยสื่อสาร
L08 captionไทยใหญ่คมชัดไม่เกินสองบรรทัด ห้ามบังตา ปาก และมือที่สื่อintent รักษาสระ/วรรณยุกต์ครบ
ภาพท่าฝึกทุกภาพยังใช้ชุดapprovedเดิม ห้ามตีความเป็นเปลี่ยนเครื่องแบบหรือสร้างอาวุธเพื่อสื่อการฝึก
