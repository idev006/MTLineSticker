# NEGATIVE_CONSTRAINTS — เข้น้อย อยู่ระหว่างฝึก

## Forbidden changes
ไม่เปลี่ยนหัวจระเข้หรือทำตัวเด็ก ไม่มีหางหรือมือสัตว์ ห้ามเปลี่ยนชุดapprovedเป็นชุดสนาม/เสื้อกีฬาเพราะธีมฝึก ไม่เปิดคอหรือทำไทดำ ไม่เพิ่มตราโรงเรียนหรือยศ

## Reference exclusions
ไม่ใช้candidate01/02จากชุดเดิมที่ถูกปฏิเสธ ไม่ใช้ภาพมีมฉากร้านเป็นbackground ไม่ยกชื่อcaptionแผนHeroเก่ามาแทนbriefชุดใหม่ ห้ามใช้referencetextแทนไฟล์ภาพactual

## Rendering defects
ปฏิเสธตาเหมือนกันทุกภาพ มือเกินนิ้ว ปากเปลี่ยนรูป หน้าเล็กเพราะpropsใหญ่ สระวรรณยุกต์ถูกตัด ข้อความชนกรอบหรือหน้า เงา/เหงื่อหลุดไดคัท และพื้นcheckerboardจำลองแทนalphaจริง
