# SET-008 — HERO STICKER PLAN v1.0

## Purpose
สร้าง Hero Set เพื่อทดสอบ likeness, expression clarity, gesture readability และ visual consistency ก่อนผลิต Full 40

## Hero Set — 12 Frames
1. ทักทาย — greeting / mild smile
2. กลัว — controlled fear
3. ตกใจ — controlled surprise
4. เยี่ยมมาก — thumbs up
5. OK — OK hand
6. ไม่โอเค — head shake + reject palm
7. กังวลใจ — thoughtful concern
8. ปลาบปลื้ม — hand on chest / warm smile
9. โกรธ — controlled anger
10. กำลังยุ่ง — multitask / occupied
11. ประชุมอยู่ — meeting participation
12. อนุมัติ — sign/stamp / approval

## Why These 12
ครอบคลุม:
- positive / negative / neutral
- subtle และ stronger emotions
- hand gestures หลายแบบ
- desk/work props
- meeting context
- authority/workflow context

## Acceptance Criteria
Hero Set ผ่านเมื่อ:
- ทั้ง 12 ภาพเป็นคนเดียวกันอย่างชัดเจน
- outfit และ body proportion ไม่ drift
- emotion อ่านได้โดยไม่มี caption
- ไม่มี pose ที่กำกวม
- face ไม่เสีย likeness เมื่อแสดงอารมณ์
- ไม่มี badminton element
- ไม่มี police uniform / rank / insignia เป็นลุคหลัก
- props ไม่บัง gesture/face

## Gate
`Gate H = PASS` ต้องได้รับ owner approval ก่อนเริ่มผลิต Full 40
