# SET-008 — PROJECT CREATIVE BRIEF v1.0

ชื่อชุด: **พงศธร**  
รหัสชุด: `SET-008-PONGSATHORN`  
สถานะ: **DOCUMENTATION COMPLETE / PRE-CHARACTER-SHEET**

## Product Purpose
สติกเกอร์ LINE สำหรับชายวัยผู้ใหญ่ซึ่งมีบทบาทเป็นผู้บังคับบัญชาระดับสูง ใช้สื่อสารกับผู้ใต้บังคับบัญชา เพื่อนร่วมงาน และผู้บังคับบัญชา โดยเน้นการสื่อสารผ่าน **ท่าทาง สีหน้า และอารมณ์** มากกว่าข้อความ

## Positioning
**ผู้นำสุขุม — สื่อสารด้วยท่าทาง**

บุคลิกหลัก:
- สุขุม มีวุฒิภาวะ
- ดูมีอำนาจโดยไม่ก้าวร้าว
- เป็นมิตรและเข้าถึงได้
- ควบคุมอารมณ์ดี
- พูดน้อย แต่สื่อสารชัด
- เหมาะกับบริบทการทำงานระดับผู้บริหาร/ผู้บังคับบัญชา

## Audience / Usage Context
ใช้ในบทสนทนา LINE กับ:
- ผู้ใต้บังคับบัญชา
- เพื่อนร่วมงาน
- ผู้บังคับบัญชา
- กลุ่มงาน/กลุ่มประชุม

## Communication Model
หลัก: **No-text / Gesture-first**
- หลีกเลี่ยง caption ในตัวสติกเกอร์
- ใช้ pose, facial expression, hand gesture และ prop ที่จำเป็น
- อนุญาต icon เชิงภาพขนาดเล็ก เช่น ✓, !, ?, นาฬิกา, โทรศัพท์, เอกสาร เมื่อช่วยให้ความหมายชัดขึ้น
- ห้ามให้ icon กลายเป็นข้อความแทน caption

## Main Outfit
ยึดภาพอ้างอิงล่าสุดเป็นชุดหลัก:
- แจ็กเก็ตกีฬาเทาเข้ม
- แถบสีขาวตามแขน
- เสื้อด้านในสีดำ
- กางเกงโทนเทาเข้มหรือดำที่สอดคล้องกับลุค
- รองเท้ากีฬา/ลำลองสุภาพที่ไม่แย่งจุดสนใจ

## Visual Direction
- semi-realistic cartoon / polished LINE sticker illustration
- likeness ของต้นแบบต้องจดจำได้
- รูปร่างสมส่วน แข็งแรง ดูดีตามวัย
- หลีกเลี่ยง chibi ที่ศีรษะใหญ่เกินจริง
- expression ชัด แต่ไม่ exaggerated แบบการ์ตูนเด็ก
- white sticker outline ชัดเจน
- transparent background สำหรับ production art

## Owner-Locked Requirements
- ชื่อชุดคือ **พงศธร**
- ไม่ใช้ badminton เป็นธีมหรือองค์ประกอบของชุด
- ไม่ใช้เครื่องแบบตำรวจเป็นลุคหลัก
- สติกเกอร์ไม่มีข้อความเป็นหลัก
- ต้องมี Core Expressions 16 รายการตาม `CORE-EXPRESSION-LIST-v1.0.md`
- ชุดหลักต้องยึดภาพอ้างอิงล่าสุด
- บุคลิกต้องคงความเป็นผู้บังคับบัญชาระดับสูง

## Production Goal
เป้าหมายเต็มชุด: **40 stickers** ที่ความหมายไม่ซ้ำหรือใกล้กันเกินไป และครอบคลุม:
1. อารมณ์พื้นฐาน
2. การตอบสนอง
3. การสั่งการ/ประสานงาน
4. การประชุม/งานเอกสาร
5. การพักผ่อนและสถานะส่วนตัว
6. การชื่นชม/ให้กำลังใจ/ปิดงาน
