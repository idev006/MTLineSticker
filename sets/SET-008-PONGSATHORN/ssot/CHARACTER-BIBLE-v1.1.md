# SET-008 — CHARACTER BIBLE v1.1

Status: **ACTIVE CHARACTER DESIGN SOURCE**  
Supersedes: `CHARACTER-BIBLE-v1.0.md`

## 1. Character Identity
ชื่อชุด: **พงศธร**

พงศธรคือคาแรกเตอร์ชายวัยผู้ใหญ่ที่มีบุคลิกของผู้บังคับบัญชาระดับสูง สุขุม มั่นคง สุภาพ มีวุฒิภาวะ และสื่อสารได้ชัดเจนโดยไม่ต้องพูดมาก

คาแรกเตอร์นี้ไม่ได้ถูกออกแบบให้เป็น “ผู้ใหญ่เคร่งขรึม” เพียงอย่างเดียว แต่ต้องมี emotional range มากพอที่จะใช้จริงใน LINE ทั้งงานและปฏิสัมพันธ์กับคนรอบตัว

## 2. Character Promise
> **พูดน้อย แต่สื่อสารชัด**

ทุกเฟรมต้องรักษาแกนนี้ไว้: ภาษากายหนึ่งท่าควรมี intent หลักหนึ่งอย่างที่ผู้ใช้เข้าใจได้เร็ว

## 3. Target-Market Fit
คาแรกเตอร์ต้องตอบโจทย์ 4 กลุ่มหลักจาก `TARGET-AUDIENCE-PERSONAS-v1.0.md`:
- ผู้บริหาร / ผู้บังคับบัญชา
- หัวหน้างาน / ผู้ประสานงาน
- เพื่อนร่วมงานระดับวิชาชีพ
- ผู้รับสารซึ่งเป็นผู้ใต้บังคับบัญชาหรือทีมงาน

### Design Consequence
- มี authority แต่ไม่ intimidating
- ดูสุภาพพอสำหรับผู้บังคับบัญชา
- เป็นมิตรพอสำหรับเพื่อนร่วมงาน
- ชัดพอสำหรับการสั่งงานหรือ feedback
- ไม่ childish และไม่ meme-heavy

## 4. Core Personality
### Primary Traits
- สุขุม
- มั่นคง
- มีภาวะผู้นำ
- น่าเชื่อถือ
- สุภาพ
- ชัดเจน
- มีความรับผิดชอบ

### Secondary Traits
- เป็นมิตร
- มีความอบอุ่น
- ผ่อนคลายได้เมื่อไม่ใช่บริบทงาน
- มีอารมณ์ขันเบา ๆ
- มี empathy

### Never Become
- ดุดันข่มคน
- เย่อหยิ่ง
- ตลกโปกฮา
- เด็กน้อย / chibi mascot
- หงุดหงิดทุกเวลา
- เย็นชาไร้อารมณ์

## 5. Visual Identity
### Face
- ต้องรักษาความคล้ายต้นแบบในระดับจดจำได้
- โครงศีรษะและใบหน้าชัด ไม่กลมเป็นลูกบอล
- คิ้วและดวงตาเป็นเครื่องมือสำคัญในการสื่อ controlled emotion
- ปากไม่ควร exaggerated มาก ยกเว้นกรณีที่จำเป็นต่อความหมาย
- ลดรายละเอียดผิวที่ทำให้ดูโทรม แต่ไม่ทำให้ดูเด็กผิดวัย

### Hair
- ผมสั้น เรียบร้อย ตาม reference
- ห้ามเปลี่ยนทรงหรือเพิ่ม volume มากจนบุคลิกเปลี่ยน

### Body
- สมส่วน แข็งแรง ดู active
- ไม่ผอมแห้ง
- ไม่อ้วนแบบ caricature
- ไม่ chibi เตี้ยหัวโตเกินไป
- stance โดยรวมมั่นคงและมี balance

## 6. Locked Outfit
ชุดหลักเป็น visual anchor ของทั้งเซ็ต:
- แจ็กเก็ตกีฬาเทาเข้ม
- แถบขาวตามแขน
- เสื้อด้านในสีดำ
- กางเกงโทนเข้มเข้าชุด
- รองเท้ากีฬา/ลำลองสุภาพที่สอดคล้องกับ reference

ห้ามเพิ่ม:
- เครื่องแบบตำรวจเป็นลุคหลัก
- ยศ
- ตรา/เครื่องหมายราชการ
- badge ที่ทำให้ชุดผูกกับหน่วยงานเฉพาะ
- badminton equipment

## 7. Style Language
- polished semi-realistic cartoon
- LINE Sticker friendly
- likeness-first but not portrait-stiff
- silhouette ชัด
- gesture อ่านง่าย
- รายละเอียดเสื้อผ้าเพียงพอให้จำชุดได้ แต่ไม่รก
- rendering สะอาด ไม่ photorealistic จนสูญเสีย readability

## 8. Leadership Body Language
ภาษากายหลักต้องสื่อ “นิ่งแต่ชัด”

### Recommended
- พยักหน้า
- ยกนิ้วโป้ง
- OK hand
- open palm
- stop palm
- arms crossed แบบคิด ไม่ใช่ข่ม
- ชี้เอกสาร / ชี้เวลา / ชี้ทิศทางอย่างสุภาพ
- มือแตะอก
- มือประสานด้านหน้า
- นั่งฟัง / leaning-in เล็กน้อยเมื่อประชุม

### Avoid
- ชี้นิ้วใส่หน้าคน
- กำหมัดข่มขู่
- posture ก้าวร้าว
- ท่าหัวเราะเยาะ
- body language แบบประชดหรือดูหมิ่น

## 9. Expression Language
หลักคือ **controlled expression**: อารมณ์ชัด แต่ผู้ใหญ่ยังควบคุมตนเองได้

### Core 16 Owner-Locked Expressions
1. ทักทาย — mild smile + raised hand
2. กลัว — slight retreat + widened eyes, no grotesque distortion
3. ตกใจ — brows raised + hands momentarily paused
4. เยี่ยมมาก — confident thumbs up + approving smile
5. OK — clear OK hand + calm face
6. ไม่โอเค — controlled head shake / stop palm
7. เศร้า — lowered gaze + slight shoulder drop
8. เสียใจ — hand near chest / regretful eyes
9. กังวลใจ — furrowed brow + thinking posture
10. ปลาบปลื้ม — warm smile + hand to chest
11. ว้าว — positive surprise, open eyes, restrained mouth
12. โกรธ — firm brows + restrained jaw, no rage caricature
13. Chill Chill — relaxed posture, slight smile
14. พักผ่อน — reclined / seated rest with peaceful face
15. กำลังยุ่ง — focused multitask posture
16. ประชุมอยู่ — attentive meeting pose

## 10. Emotion Intensity Scale
เพื่อรักษาความเป็นผู้ใหญ่ ให้กำหนดระดับ expression โดยทั่วไปดังนี้:
- Level 1: neutral / mild
- Level 2: clear everyday expression — default production level
- Level 3: strong but controlled — ใช้เฉพาะเฟรมที่ต้องการความชัดมาก
- Level 4+: prohibited unless explicitly approved

Full production ส่วนใหญ่ควรอยู่ที่ Level 2

## 11. Gesture Readability Rule
ทุก gesture ต้องผ่าน 3 tests:
1. **Silhouette Test** — มองเป็นเงายังเดาท่าหลักได้
2. **Thumbnail Test** — ย่อขนาดแล้วยังเห็นมือ/ทิศทางหลัก
3. **No-Text Test** — เอาข้อความออกแล้วยังตีความ intent ได้

## 12. Props Policy
ใช้ props เฉพาะเมื่อช่วยสื่อสารและต้องไม่แย่ง focus จากคาแรกเตอร์

Approved prop families:
- เอกสาร / แฟ้ม
- โทรศัพท์
- นาฬิกา
- ปฏิทิน
- laptop/tablet
- โต๊ะประชุม / เก้าอี้แบบ minimal
- check / alert / question icon แบบ visual symbol

Props ห้ามกลายเป็น theme หลักของชุด

## 13. Social Tone Matrix
### ส่งให้ผู้ใต้บังคับบัญชา
ต้องชัดแต่ไม่ข่ม

### ส่งให้เพื่อนร่วมงาน
ต้องเป็นธรรมชาติ เป็นมิตร และไม่ดูสั่งการทุกครั้ง

### ส่งให้ผู้บังคับบัญชา
ต้องไม่เสียมารยาท และ reaction ต้องตีความเป็น acknowledgement / respect ได้

ถ้า gesture ใดเหมาะเพียงทิศทางเดียว ให้ใช้ใน Full 40 อย่างจำกัดและต้องมี value สูงจริง

## 14. Color / Value Direction
- หลัก: charcoal / dark gray / black / white stripe
- skin tone ตาม reference
- accent จาก props/icons ใช้อย่างประหยัด
- contrast ต้องทำให้หน้าและมืออ่านง่ายบน LINE background ทั้งสว่างและมืด

## 15. Composition Rules
- หน้าและมือเป็น visual priority
- ห้ามให้ props บังมือหรือสีหน้าที่สื่อ intent
- pose ควรเต็มเฟรมแต่เหลือ safety margin สำหรับ export
- crop ได้ตั้งแต่ bust-up ถึง full-body ตาม intent
- งานที่ใช้มือเป็นหลักควรจัดมุมกล้องให้มืออ่านง่าย

## 16. Prohibited Drift
ห้าม drift ใน:
- facial structure
- head silhouette
- hairstyle
- body build
- apparent age
- locked outfit
- rendering language
- personality tone

ห้าม:
- badminton content
- police insignia / rank as main identity
- childish exaggeration
- excessive wrinkles / frailty
- aggressive intimidation

## 17. Success Definition
Character Bible ถือว่าถูกนำไปใช้สำเร็จเมื่อผู้ดูเห็นหลายเฟรมแล้วรู้ทันทีว่าเป็น “คนเดียวกัน” และเข้าใจว่าเขาเป็นผู้ใหญ่ที่สุขุม มี authority แต่ยังเข้าถึงได้
