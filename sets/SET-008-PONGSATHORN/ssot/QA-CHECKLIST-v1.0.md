# SET-008 — QA CHECKLIST v1.0

## A. Character Identity
- [ ] ใบหน้าคง likeness ของต้นแบบ
- [ ] รูปศีรษะไม่กลม/บิดเบี้ยวเกินจริง
- [ ] ทรงผมคงที่
- [ ] visual age เหมาะสม ไม่แก่โทรม ไม่เด็กเกินจริง
- [ ] body build สมส่วน แข็งแรง

## B. Outfit
- [ ] แจ็กเก็ตเทาเข้มถูกต้อง
- [ ] แถบขาวตามแขนถูกต้องและ consistent
- [ ] เสื้อด้านในสีดำ
- [ ] ไม่มีตรา ยศ เครื่องหมาย หรือโลโก้ราชการที่ไม่ได้อนุมัติ

## C. Gesture / Expression
- [ ] intent อ่านออกได้โดยไม่มี caption
- [ ] มือไม่ผิดรูป / นิ้วไม่เกิน / ไม่มี duplicate limbs
- [ ] gesture สำคัญไม่ถูก crop
- [ ] face expression ไม่ทำให้ likeness หาย
- [ ] emotional intensity เหมาะกับบุคลิกผู้บังคับบัญชาระดับสูง

## D. No-Text / Theme
- [ ] ไม่มี caption หรือ speech bubble โดยไม่จำเป็น
- [ ] icon ถูกใช้เพียงเล็กน้อยและไม่แย่งตัวละคร
- [ ] ไม่มี badminton racket/shuttlecock/court motif
- [ ] ไม่ใช้เครื่องแบบตำรวจเป็นลุคหลัก

## E. Composition
- [ ] silhouette อ่านง่าย
- [ ] props ไม่บังหน้า/มือ
- [ ] มี safe space รอบตัวละคร
- [ ] detail ไม่แน่นเกินไปเมื่อย่อภาพ
- [ ] transparent background สำหรับ production art

## F. Set-Level Diversity
- [ ] 40 intent ไม่ซ้ำหรือใกล้กันเกินไป
- [ ] pose ไม่ซ้ำจนรู้สึกเป็นภาพเดิมเปลี่ยนมือเล็กน้อย
- [ ] มีสมดุล positive / negative / work / status / reaction
- [ ] 16 owner-locked core expressions ครบ
