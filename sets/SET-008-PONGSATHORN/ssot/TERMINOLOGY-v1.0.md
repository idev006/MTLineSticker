# SET-008 — TERMINOLOGY v1.0

## Owner-locked terminology
สำหรับสติ๊กเกอร์ชุด **พงศธร** ให้ใช้คำต่อไปนี้เป็นคำมาตรฐานในการสื่อสารและจัดทำเอกสาร:

- **Sticker Sheet / สติ๊กเกอร์ชีท** = ไฟล์ภาพหนึ่งไฟล์ที่ประกอบด้วยสติ๊กเกอร์หลายภาพเพื่อใช้ตรวจ ทบทวน หรือผลิตเป็นชุด
- **Frame / เฟรม** = สติ๊กเกอร์แต่ละภาพที่อยู่ภายใน Sticker Sheet หนึ่งช่องต่อหนึ่ง intent / pose / expression

## Usage rule
- เอกสารใหม่ของ SET-008 ให้ใช้คำว่า `Sticker Sheet` และ `Frame` ตามความหมายนี้
- เมื่อระบุลำดับ ให้ใช้รูปแบบ `Frame 01`, `Frame 02`, ...
- Hero review สามารถรวมหลาย Hero Frames ใน `Hero Sticker Sheet`
- Production review สามารถแบ่ง Full 40 เป็นหลาย `Production Sticker Sheets`

คำศัพท์นี้เป็น owner-locked terminology ของ SET-008 และให้มีผลเหนือถ้อยคำทั่วไปที่อาจใช้สลับกันในเอกสารเก่า
