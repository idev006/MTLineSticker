## Expression Rules
- No text เป็นค่าเริ่มต้น
- ความหมายต้องชัดจาก silhouette, face, hands และ posture
- หลีกเลี่ยงอารมณ์ที่โอเวอร์จนลดภาพลักษณ์ผู้บังคับบัญชาระดับสูง
- แต่ละ expression ต้องแตกต่างกันอย่างชัดเจนเมื่อดูในขนาดเล็ก
- อนุญาต props เฉพาะที่ช่วยอ่านความหมาย เช่น เอกสาร โทรศัพท์ โต๊ะประชุม เครื่องดื่ม
- ห้ามใช้ไม้แบด ลูกขนไก่ หรือ visual cue ที่สื่อถึงแบดมินตัน
