# Project Creative Brief v0.1 — พงศธร

## Objective
สร้าง LINE Sticker สำหรับการสื่อสารในบริบทการทำงานของชายต้นแบบ ซึ่งเป็นผู้บังคับบัญชาระดับสูง โดยต้องสามารถใช้กับผู้ใต้บังคับบัญชา เพื่อนร่วมงาน และผู้บังคับบัญชาได้อย่างเหมาะสม

## Product Positioning
**ผู้นำสุขุม — สื่อสารด้วยท่าทาง**

คาแรกเตอร์ต้องให้ความรู้สึก:
- สุขุม
- นิ่ง
- มั่นคง
- สุภาพ
- มีอำนาจโดยไม่ก้าวร้าว
- เป็นมิตรพอให้ใช้ในชีวิตการทำงานประจำวัน
- ควบคุมอารมณ์ได้ดี

## Communication Strategy
ใช้แนวทาง **No-text / Gesture-first** เป็นหลัก
- หลีกเลี่ยงข้อความ/แคปชั่นในสติกเกอร์
- ใช้ facial expression, hand gesture, posture และ props เท่าที่จำเป็น
- ความหมายของแต่ละเฟรมต้องอ่านออกได้รวดเร็วแม้ย่อขนาด
- แต่ละเฟรมต้องมีหน้าที่สื่อสารต่างกัน หลีกเลี่ยงท่าทางที่มีความหมายซ้ำหรือใกล้เคียงกันเกินไป

## Visual Direction
- ใช้ภาพบุคคลอ้างอิงทั้งหมดเพื่อรักษาความคล้าย
- เสื้อผ้าหลักยึดภาพอ้างอิงล่าสุด: แจ็กเก็ตกีฬาเทาเข้ม แถบสีขาวที่แขน เสื้อด้านในสีดำ
- ไม่ใช้เครื่องแบบตำรวจเป็นชุดหลัก
- ไม่ใช้ธีมแบดมินตันหรืออุปกรณ์แบดมินตัน
- Semi-realistic cartoon ที่เหมาะกับ LINE Sticker
- สัดส่วนสมจริงแบบ stylized ไม่ chibi เกินไป
- สีหน้าอ่านง่าย แต่ไม่ exaggerated แบบการ์ตูนเด็ก
- พื้นหลังโปร่งใสสำหรับ production sticker
- ใช้ white outline ตามความเหมาะสมเพื่อให้อ่านง่ายบนพื้นหลังหลายสี

## Emotional Balance
เป้าหมายภาพรวม:
- สุขุม/เป็นทางการ 45%
- จริงจัง/เด็ดขาด 25%
- อบอุ่น/เป็นมิตร 20%
- อารมณ์ขัน/ผ่อนคลาย 10%

## Production Workflow
Character Sheet / Expression Sheet -> Owner Review -> Visual Lock -> Hero Set -> Hero Approval -> Full 40 -> QA -> Export
