# SET-008 — TARGET AUDIENCE PERSONAS v1.0

## Purpose
กำหนดกลุ่มเป้าหมายและพฤติกรรมการใช้งาน เพื่อให้ Character Design, gesture, expression และ Full 40 ตรงกับผู้ใช้จริง ไม่ใช่เพียงเหมือนบุคคลต้นแบบ

## Persona 1 — Senior Commander / Executive User
**บทบาท:** ผู้บังคับบัญชา ผู้บริหาร หัวหน้าหน่วย หัวหน้าทีมระดับสูง  
**อายุโดยประมาณ:** 40–65+  
**พฤติกรรม:** ใช้ LINE เป็นเครื่องมือสื่อสารงาน ต้องตอบเร็วหลายแชต ไม่ต้องการพิมพ์ยาวทุกครั้ง

### Needs
- สื่อสารสั้นแต่ไม่เสียมารยาท
- แสดง approval / rejection / acknowledgement ได้ทันที
- บอกสถานะ เช่น ยุ่ง ประชุม รอ ตรวจงาน
- รักษาภาพลักษณ์ที่สุขุมและน่าเชื่อถือ

### Design Implication
- gesture ต้องชัด
- สีหน้าไม่เวอร์
- ชุดดูสุภาพและร่วมสมัย
- หลีกเลี่ยงมุกที่ทำให้บุคลิกดูเบาเกินไป

## Persona 2 — Mid-level Manager / Coordinator
**บทบาท:** หัวหน้างาน ผู้ประสานงาน ผู้จัดการ เจ้าหน้าที่อาวุโส  
**อายุโดยประมาณ:** 30–55

### Needs
- ใช้ตอบทั้งคนบนและคนล่าง
- ต้องการสติกเกอร์ที่สุภาพแต่ไม่เป็นพิธีการเกินไป
- ใช้ reaction ได้หลายบริบท เช่น รับทราบ เห็นด้วย กังวล ขอแก้ ตรวจงาน และให้กำลังใจ

### Design Implication
- ต้องมี emotional range มากกว่าคาแรกเตอร์ที่เคร่งอย่างเดียว
- ไม่ใช้ gesture ที่ดูสั่งการแข็งทุกเฟรม
- positive reaction ต้องมีเพียงพอ

## Persona 3 — Professional Peer / Colleague
**บทบาท:** เพื่อนร่วมงานระดับใกล้เคียงกัน  
**อายุโดยประมาณ:** 25–60

### Needs
- ใช้ทักทาย ชื่นชม แสดงความเห็นใจ ผ่อนคลาย หรือบอกว่ายุ่ง/ประชุมอยู่
- ต้องการความเป็นมนุษย์และเป็นมิตร ไม่ใช่มีแต่ภาพ authority

### Design Implication
- ต้องมี chill, rest, wow, pleased, sad, worried
- รอยยิ้มและภาษากายต้องอบอุ่นพอสำหรับ peer communication

## Persona 4 — Subordinate / Team Member Receiving Stickers
**บทบาท:** ผู้ใต้บังคับบัญชาหรือทีมงานที่ได้รับสติกเกอร์จากตัวละครนี้

แม้ไม่ใช่ผู้ซื้อหลัก แต่เป็นผู้รับสารสำคัญ จึงต้องออกแบบไม่ให้ gesture ถูกตีความเป็นการข่มหรือประชด

### Reception Goal
เมื่อได้รับสติกเกอร์ ผู้รับควรรู้สึกว่า:
- เข้าใจสิ่งที่หัวหน้าต้องการ
- ไม่รู้สึกถูกตำหนิแรงเกินจำเป็น
- แยกออกระหว่าง “ไม่โอเค”, “ให้แก้”, “รอ”, “ด่วน”, “อนุมัติ” ได้ชัด

## Cross-Persona Requirements
ทุก persona ต้องใช้ชุดเดียวกันได้โดยไม่รู้สึกว่าภาษา visual ผิดระดับความสัมพันธ์

ดังนั้น character tone ต้องอยู่ตรงกลางระหว่าง:
- authority ↔ friendliness
- formality ↔ accessibility
- realism ↔ sticker expressiveness

## Message Priority Model
เรียงความสำคัญของ intents ในการออกแบบ:
1. เข้าใจทันที
2. ไม่กำกวม
3. สุภาพ
4. สอดคล้องกับบุคลิก
5. มี emotional appeal
6. สวยงาม

ความสวยงามต้องไม่มาก่อนความชัดเจนของการสื่อสาร

## Audience Fit Checklist
แต่ละเฟรมควรถามว่า:
- ผู้บริหารส่งให้ผู้ใต้บังคับบัญชาได้หรือไม่?
- เพื่อนร่วมงานส่งหากันได้หรือไม่?
- ผู้ใช้ส่งให้ผู้บังคับบัญชาได้หรือไม่?
- ไม่มีคำพูดแล้วยังเข้าใจหรือไม่?
- ท่าทางดูสุภาพและมีวุฒิภาวะหรือไม่?

ถ้าคำตอบส่วนใหญ่ไม่ใช่ ให้พิจารณาปรับ pose หรือ intent ก่อน production
