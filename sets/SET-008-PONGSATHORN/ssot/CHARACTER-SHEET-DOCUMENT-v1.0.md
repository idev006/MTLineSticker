# SET-008 — CHARACTER SHEET DOCUMENT v1.0

Status: **ACTIVE PRE-PRODUCTION DOCUMENT**

## 1. Purpose
เอกสารนี้กำหนดโครงสร้าง Character Sheet สำหรับชุด **พงศธร** เพื่อให้การอนุมัติคาแรกเตอร์เป็นระบบ ก่อนเข้าสู่ Hero Sticker และ Full 40 production

Character Sheet ต้องพิสูจน์ 4 เรื่องพร้อมกัน:
1. likeness — ยังจำได้ว่าเป็นบุคคลต้นแบบ
2. consistency — ทุกมุมและทุกอารมณ์เป็นคนเดียวกัน
3. market fit — บุคลิกตรงกับกลุ่มผู้บริหาร/คนทำงานวัยผู้ใหญ่
4. sticker usability — gesture และ expression อ่านง่ายเมื่อย่อเป็น LINE Sticker

## 2. Primary Character Direction
คาแรกเตอร์ต้องสื่อ:
- senior leadership
- calm authority
- respectful professionalism
- approachable maturity
- controlled emotion

Key phrase:
> **ผู้นำสุขุม — พูดน้อย แต่สื่อสารชัด**

## 3. Outfit Lock
ทุก panel ใช้ชุดเดียวกัน:
- แจ็กเก็ตกีฬาเทาเข้ม
- แถบขาวตามแขน
- เสื้อด้านในสีดำ
- กางเกงโทนเข้ม
- รองเท้ากีฬา/ลำลองสุภาพตามแนว reference

ห้ามใช้เครื่องแบบตำรวจ ยศ ตรา หรือเครื่องหมายราชการเป็นลุคหลัก

## 4. Sheet Architecture
แนะนำให้สร้างเป็น Master Character Sheet ขนาดกว้าง โดยแบ่งอย่างน้อย 5 zones

### Zone A — Identity Header
แสดง:
- ชื่อ: พงศธร
- set code: `SET-008-PONGSATHORN`
- style tag: semi-realistic cartoon / LINE Sticker friendly
- wardrobe swatches แบบย่อ

### Zone B — Turnaround
ต้องมี:
1. front full-body
2. 3/4 left
3. left profile
4. back
5. right profile
6. 3/4 right

ทุก view ต้องใช้สัดส่วนเดียวกันและยืนใน neutral stance เพื่อเทียบ anatomy ได้

### Zone C — Head / Face Construction
ต้องมี close-up อย่างน้อย:
- front head
- 3/4 head
- side head

ให้ตรวจ:
- forehead proportion
- head silhouette
- jaw / cheek structure
- eyebrow shape
- eye spacing
- nose and mouth relationship
- hairstyle / hairline

### Zone D — Expression Matrix
อย่างน้อย 16 expressions ที่ owner lock:
1. ทักทาย
2. กลัว
3. ตกใจ
4. เยี่ยมมาก
5. OK
6. ไม่โอเค
7. เศร้า
8. เสียใจ
9. กังวลใจ
10. ปลาบปลื้ม
11. ว้าว
12. โกรธ
13. Chill Chill
14. พักผ่อน
15. กำลังยุ่ง
16. ประชุมอยู่

Expression Matrix ต้องรักษาใบหน้าเดิม และใช้ controlled expression ตาม Character Bible

### Zone E — Gesture / Work-Use Matrix
ต้องมี gesture validation อย่างน้อย:
- thumbs up
- OK hand
- stop palm
- open palm / invite
- point / explain
- arms crossed / thinking
- hand to chest
- hold/read document
- look at watch
- use phone
- listening in meeting
- multitasking / busy

## 5. Proportion System
### Head-to-body
ใช้สัดส่วน semi-realistic cartoon ไม่ chibi

Target impression:
- ผู้ใหญ่ดูแข็งแรง
- ศีรษะใหญ่ขึ้นจาก realism ได้เล็กน้อยเพื่อ readability
- มืออาจ enlarge เล็กน้อยเพื่อ gesture clarity
- ห้ามทำให้หัวใหญ่จนเสีย dignity

### Body
- shoulders stable
- posture upright
- torso proportional
- limbs ไม่สั้นแบบ mascot

## 6. Face Consistency Rules
ทุก panel ต้องคง:
- head width/height relationship
- eyebrow baseline
- eye spacing
- nose length
- jawline
- hairline
- ear position

Expression เปลี่ยนได้ แต่ facial anatomy ห้าม drift

## 7. Age Treatment
เป้าหมายคือ mature and healthy

### Allowed
- เส้นอายุเล็กน้อยที่ช่วย likeness
- maturity around eyes / cheeks แบบ subtle

### Avoid
- wrinkles หนาเกินไป
- eye bags ที่ทำให้ดูอ่อนแรง
- sagging face แบบ exaggerated
- de-aging จนดูเป็นคนละช่วงวัย

## 8. Expression Calibration
ทุก expression ใช้ระดับประมาณ Level 2 จาก Character Bible เป็นค่าเริ่มต้น

### Examples
- โกรธ: คิ้วขมวด + jaw firm; ห้ามตาแดง/เส้นเลือด/ไฟลุก
- กลัว: ถอยเล็กน้อย + widened eyes; ห้ามสั่นทั้งตัวแบบ slapstick
- ว้าว: positive surprise; ห้ามอ้าปากกว้างผิด anatomy
- เศร้า: gaze down + soft mouth; ไม่จำเป็นต้องร้องไห้
- ปลาบปลื้ม: warm smile + hand to chest

## 9. Gesture Readability
มือเป็นส่วนสำคัญของผลิตภัณฑ์ no-text

ต้องตรวจ:
- จำนวน/รูปนิ้วไม่ผิด
- gesture silhouette ชัด
- มือไม่บังหน้า
- perspective มือไม่ผิดจนเสียความน่าเชื่อถือ
- gesture เข้าใจโดยไม่ต้องมี caption

## 10. Props Validation
Character Sheet ควร test props หลัก:
- document/folder
- phone
- watch
- laptop/tablet
- minimal meeting table

Props ใช้เป็น communication aids เท่านั้น

## 11. Market-Fit Review Panel
ก่อนอนุมัติ Character Sheet ให้ทีมตรวจ 4 questions:
1. ดูแล้วเชื่อว่าเป็นผู้ใหญ่/ผู้นำหรือไม่?
2. ดูสุภาพพอที่จะใช้ในงานจริงหรือไม่?
3. ยังเป็นมิตรและเข้าถึงได้หรือไม่?
4. สามารถแสดง 16 core emotions โดยไม่หลุด persona หรือไม่?

ถ้าคำตอบข้อใดข้อหนึ่งไม่ผ่าน ให้ revise ก่อน Visual Lock

## 12. Technical Presentation
- master sheet background: white / light neutral เพื่อ review
- production stickers ภายหลัง: transparent
- ไม่มี decorative background ที่รบกวนการตรวจ shape
- label panel ได้ใน character sheet document แต่ labels ไม่ใช่ส่วนหนึ่งของ sticker art
- canvas ต้องใหญ่พอให้ตรวจหน้า มือ และรายละเอียดชุด

## 13. Recommended Deliverables
ก่อน C2 approval ควรมี:
1. `CHARACTER_SHEET_CANDIDATE-01.png`
2. optional detail sheet for face/hand corrections
3. owner review notes
4. approved asset renamed/designated as `CHARACTER_SHEET_ACTIVE`

## 14. Rejection Criteria
Reject หากพบ:
- likeness ไม่สม่ำเสมอ
- หน้าเปลี่ยนตาม expression
- รูปร่าง drift
- ชุดผิดจาก lock
- ดูเด็ก/chibi เกินไป
- ดูแก่/โทรมเกินไป
- gesture อ่านไม่ออก
- โกรธ/กลัว/ตกใจ exaggerated เกิน persona
- มี badminton element
- มี police insignia / rank เป็นส่วนเด่น

## 15. Approval Gate C2
Gate C2 ผ่านเมื่อ Product Owner ระบุชัดว่า Character Sheet Candidate ได้รับอนุมัติ

หลังจากนั้น:
- asset นั้นคือ `CHARACTER_SHEET_ACTIVE`
- Hero production ต้องยึด sheet นี้
- ห้ามปรับ facial identity หรือ wardrobe เองโดยไม่มี revision approval
