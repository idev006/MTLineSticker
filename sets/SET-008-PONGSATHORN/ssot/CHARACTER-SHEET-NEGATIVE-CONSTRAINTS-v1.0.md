# SET-008 — CHARACTER SHEET NEGATIVE CONSTRAINTS v1.0

Reject output if any critical condition below occurs.

## Identity / Face
- ใบหน้าไม่คล้ายต้นแบบจนจดจำไม่ได้
- ศีรษะกลม/ป่องเกินจริง
- ทรงผมเปลี่ยน
- ทำให้ดูเด็กเกินจริงหรือแก่โทรมเกินจริง
- wrinkle/eye bag มากจนภาพลักษณ์อ่อนแรง

## Body
- chibi มากเกินไป
- ผอมแห้ง อ้วนเกินจริง หรือกล้ามใหญ่เกินต้นแบบ
- สัดส่วนแขนขาผิดธรรมชาติ

## Outfit
- เปลี่ยนสีหรือโครงสร้างแจ็กเก็ตหลัก
- ไม่มีแถบขาวตามแขนโดยไม่มีเหตุผล
- เพิ่ม police uniform, rank, insignia, badge หรือ emblem เป็นลุคหลัก
- เพิ่มโลโก้ที่ไม่ได้รับอนุมัติ

## Theme
- ห้าม badminton racket
- ห้าม shuttlecock
- ห้าม court / badminton motif
- ห้ามทำให้กีฬาเป็น character identity ของชุดนี้

## Expression
- ห้าม exaggerated slapstick
- ห้าม mouth/eye deformation จน likeness หาย
- ห้ามอารมณ์รุนแรงจนดูคุกคาม
- ห้าม expression กำกวมจนไม่สามารถตีความ intent ได้

## Text / Graphic
- ห้าม caption หรือ speech bubble เป็นค่าเริ่มต้น
- ห้ามใช้ตัวอักษรจำนวนมาก
- icon ใช้ได้เฉพาะเพื่อช่วยความหมายและต้องไม่แย่งตัวละคร

## Production Quality
- ห้าม crop มือ/gesture สำคัญ
- ห้าม props บังใบหน้า
- ห้ามมี extra fingers / malformed hands
- ห้ามมี duplicate limbs
- ห้าม inconsistency ระหว่างแต่ละ view
