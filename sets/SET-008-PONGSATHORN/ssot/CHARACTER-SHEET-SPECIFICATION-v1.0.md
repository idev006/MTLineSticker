# SET-008 — CHARACTER SHEET SPECIFICATION v1.0

## Purpose
สร้าง Character Sheet Candidate เพื่อใช้ตรวจ likeness, body proportion, outfit consistency และ expression language ก่อนอนุมัติเป็น `CHARACTER_SHEET_ACTIVE`

## Required Views
อย่างน้อยต้องมี:
1. Front full body
2. 3/4 left
3. 3/4 right
4. Side profile
5. Back view
6. Neutral standing pose

## Required Expression Panel
ต้องแสดงตัวอย่างอย่างน้อย:
- neutral
- mild smile
- serious
- worried
- surprised
- angry controlled
- pleased/proud
- sad/regretful

## Required Gesture Samples
- ยกมือทักทาย
- thumbs up
- OK hand
- palm stop / reject
- arms crossed thinking
- point / explain
- hold document
- meeting/listening pose

## Outfit Lock
ทุก view ต้องใช้ชุดหลักเดียวกัน:
- แจ็กเก็ตเทาเข้ม
- แถบขาวตามแขน
- เสื้อด้านในสีดำ
- กางเกงโทนเข้มที่เข้าชุด

## Visual Style
- polished semi-realistic cartoon
- LINE sticker friendly
- clean silhouette
- line weight สม่ำเสมอ
- facial likeness ต้องคงที่ทุก view
- body proportion ไม่ chibi เกินไป

## Sheet Layout Guidance
แนะนำ A3/A4 landscape หรือ canvas กว้างที่อ่านรายละเอียดได้ดี แบ่งเป็น:
- row 1: turnaround views
- row 2: expressions
- row 3: gesture / prop tests

## Background
- Character Sheet ใช้พื้นขาวหรือ neutral ได้เพื่อ review
- Production sticker ภายหลังต้อง transparent

## Approval Criteria
ผ่านเมื่อ:
- likeness จดจำได้
- อายุและบุคลิกเหมาะสม
- outfit consistent
- 8 expressions ยังเป็นคนเดียวกัน
- gesture อ่านง่าย
- ไม่มี badminton element
- ไม่มี police uniform / rank / insignia เป็นลุคหลัก

เมื่อเจ้าของอนุมัติ ให้ระบุภาพนั้นเป็น `CHARACTER_SHEET_ACTIVE` และใช้เป็น visual SSOT เหนือ prompt generation ต่อ ๆ ไป
