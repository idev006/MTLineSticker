# SET-008 — PRODUCT SSOT v1.0

## Identity
- Set code: `SET-008-PONGSATHORN`
- Set name: **พงศธร**
- Product type: LINE Sticker Set
- Target quantity: 40

## Product Positioning
**ผู้นำสุขุม — สื่อสารด้วยท่าทาง**

สติกเกอร์สำหรับชายวัยผู้ใหญ่ซึ่งเป็นผู้บังคับบัญชาระดับสูง ใช้กับผู้ใต้บังคับบัญชา เพื่อนร่วมงาน และผู้บังคับบัญชา โดยเน้น no-text / gesture-first communication

## Product Promise
> **พูดน้อย แต่สื่อสารชัด**

## Strategic Market Goal
สร้างสติกเกอร์บุคคลที่ใช้จริงในบริบทการทำงานได้บ่อย มีความน่าเชื่อถือ สุภาพ และมี emotional range โดยไม่ลดทอนภาพลักษณ์ของผู้ใหญ่หรือผู้บังคับบัญชา

Market strategy ใช้ `MARKETING-POSITIONING-STRATEGY-v1.0.md` เป็น active source และ audience model ใช้ `TARGET-AUDIENCE-PERSONAS-v1.0.md`

## Primary Target Audiences
1. ผู้บังคับบัญชา / ผู้บริหาร / senior leaders
2. หัวหน้างาน / manager / coordinator
3. เพื่อนร่วมงานระดับวิชาชีพ
4. ผู้รับสารที่เป็นผู้ใต้บังคับบัญชาหรือทีมงาน

## Owner-Locked Decisions
1. ชื่อชุดคือ **พงศธร**
2. ชุดหลัก: แจ็กเก็ตกีฬาเทาเข้ม แถบขาวตามแขน เสื้อด้านในสีดำ
3. ไม่มี badminton theme
4. ไม่ใช้เครื่องแบบตำรวจเป็นลุคหลัก
5. ไม่มี caption เป็นหลัก
6. ต้องมี 16 core expressions/statuses ตาม `CORE-EXPRESSION-LIST-v1.0.md`
7. Full 40 ใช้ `FULL-STICKER-PRODUCTION-TABLE-v1.0.md`
8. บุคลิก: สุขุม มีภาวะผู้นำ ดูมีอำนาจแต่ไม่ก้าวร้าว
9. Character ต้อง balance authority + friendliness + respect + clarity
10. ห้ามออกแบบไปในทาง childish, slapstick, intimidating หรือ meme-driven
