# SET-008 — CHARACTER BIBLE v1.0

## Character Identity
ชื่อชุด: **พงศธร**

ต้นแบบเป็นชายวัยผู้ใหญ่ บุคลิกสุขุม มีวุฒิภาวะ และมีสถานะเป็นผู้บังคับบัญชาระดับสูง การออกแบบต้องรักษาความน่าเชื่อถือและความเป็นมิตรพร้อมกัน

## Core Personality
- สุขุม
- มั่นคง
- มีภาวะผู้นำ
- สุภาพ
- ไม่โอเวอร์แอ็กติ้ง
- เป็นมิตรเมื่อเหมาะสม
- แสดงอารมณ์ชัดแต่ยังควบคุมตัวเองได้

## Visual Identity
- รักษาความคล้ายต้นแบบในระดับจดจำได้
- ศีรษะและรูปหน้าต้องมีโครงสร้าง ไม่กลมเป็นลูกบอล
- ผมสั้น เรียบร้อย ตามภาพอ้างอิง
- รูปร่างสมส่วน ดูแข็งแรง ไม่ผอมแห้ง ไม่อ้วนเกินจริง
- อายุภาพต้องดูดีตามวัย ไม่ทำให้ดูโทรม แก่จัด หรืออ่อนแรง

## Locked Outfit
- แจ็กเก็ตกีฬาเทาเข้ม
- แถบขาวตามแขน
- เสื้อด้านในสีดำ
- กางเกงโทนเข้มที่สอดคล้องกับชุด
- ไม่มีตรา หน่วยงาน ยศ หรือเครื่องหมายราชการเป็นองค์ประกอบหลัก

## Expression Language
ใช้ `controlled expression` เป็นหลัก:
- โกรธ = สีหน้าเข้ม คิ้วขมวด กำมือหรือกอดอกอย่างควบคุม
- กลัว = ถอยเล็กน้อย ตาเปิดกว้าง แต่ไม่ทำหน้าเสียรูป
- ตกใจ = คิ้วยก ตาโต มือชะงัก
- เศร้า/เสียใจ = ลดสายตา ไหล่ตกเล็กน้อย ไม่ร้องไห้เวอร์
- ปลาบปลื้ม = ยิ้มอ่อน มือแตะอก ตาเป็นประกาย
- ว้าว = ประหลาดใจเชิงบวก ไม่อ้าปากกว้างเกินไป

## Gesture Language
มือและท่าทางต้องอ่านได้ในขนาดสติกเกอร์จริง:
- gesture หลักต้องเด่นกว่ารายละเอียดรอง
- หลีกเลี่ยงท่ามือซับซ้อนหรือกำกวม
- อนุญาต props เมื่อช่วยลดความกำกวม เช่น เอกสาร โทรศัพท์ นาฬิกา แล็ปท็อป

## No-Text Rule
- ห้ามใส่ caption เป็นค่าเริ่มต้น
- หลีกเลี่ยงตัวอักษร/คำพูดใน speech bubble
- ใช้ icon เชิงภาพได้เฉพาะเมื่อจำเป็น เช่น ✓ ! ?

## Prohibited Drift
ห้ามเปลี่ยน:
- รูปหน้าแบบมีนัยสำคัญ
- ทรงผม
- body build
- outfit หลัก
- อายุภาพ
- visual style

ห้ามเพิ่ม badminton racket, shuttlecock หรือธีมแบดมินตัน

## Tone Guardrail
แม้เฟรมจะเป็นอารมณ์ขัน ต้องไม่ลดทอนภาพลักษณ์ของผู้บังคับบัญชาระดับสูงจนกลายเป็นตัวตลกหรือ slapstick character
