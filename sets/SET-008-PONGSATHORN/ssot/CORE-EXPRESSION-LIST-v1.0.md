## Expression Rules
- อารมณ์ต้องอ่านออกได้โดยไม่ต้องมี caption
- ไม่ exaggerate จนเสีย likeness หรือ dignity
- หลีกเลี่ยงการใช้ emoji face แทนการแสดงอารมณ์ของตัวละคร
- props ต้องเป็นรองต่อ face + gesture
- ทั้ง 16 intent ห้ามถูกตัดออกจาก Full 40 โดยไม่มี owner approval
