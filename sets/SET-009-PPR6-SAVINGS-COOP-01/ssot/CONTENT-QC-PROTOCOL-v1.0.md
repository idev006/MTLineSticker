# CONTENT QC PROTOCOL v1.0 — SET-009

## Purpose
กำหนดขั้นตอน QC หลังออกแบบรายการสติ๊กเกอร์ครบ เพื่อให้ชุดสติ๊กเกอร์ใช้งานได้หลากหลายจริง โดยลดความซ้ำทั้งด้านข้อความ ความหมาย ท่าทาง สีหน้า และพร็อพ

## Core Rule
ก่อนล็อก FULL-STICKER-PRODUCTION-TABLE เป็น Production SSOT ต้องผ่าน Content QC รอบหนึ่งเสมอ

## QC Dimensions
ตรวจทุกเฟรมเทียบกันทั้งชุดใน 6 มิติ:
1. Caption — ถ้อยคำต้องไม่ซ้ำหรือใกล้เคียงเกินไป
2. Intent — จุดประสงค์การสื่อสารต้องไม่ทับซ้อนกันจนใช้งานแทนกันได้แทบทั้งหมด
3. Pose / Gesture — ท่าทางหลักต้องไม่ซ้ำหรือแตกต่างเพียงเล็กน้อย
4. Facial Expression — สีหน้าต้องช่วยขยาย intent และไม่ใช้ expression เดิมซ้ำเกินจำเป็น
5. Prop — พร็อพต้องมีเหตุผลและช่วยสื่อสาร หลีกเลี่ยงการใช้ของเดิมซ้ำโดยไม่จำเป็น
6. Usage Scenario — แต่ละเฟรมควรมีบริบทใช้งานชัดเจนสำหรับเจ้าหน้าที่สหกรณ์และ/หรือสมาชิกสหกรณ์

## Similarity Review
ให้ทีม QC จัดกลุ่มเฟรมที่มีความหมายหรือภาพใกล้กัน แล้วตัดสินว่า:
- KEEP — ต่างกันชัด ใช้งานคนละสถานการณ์
- REWORK — ยังใกล้กันเกินไป ต้องแก้ caption / pose / expression / prop
- REPLACE — ซ้ำเชิงหน้าที่หรือภาพมากเกินไป ควรเปลี่ยน intent ใหม่

## Acceptance Criteria
- ไม่มี caption ซ้ำตรงตัว
- ไม่มี caption ที่ต่างเพียงคำเล็กน้อยแต่ intent เดียวกันโดยไม่จำเป็น
- ไม่มี 2 เฟรมที่ใช้ pose หลักแทบเหมือนกันและสื่อความหมายใกล้กัน
- แต่ละเฟรมมีเหตุผลว่าผู้ใช้จะเลือกใช้เมื่อใด
- ชุดรวมมีความหลากหลายด้านอารมณ์: ทักทาย, สุภาพ, ขอบคุณ, งานบริการ, รอคอย, สำเร็จ, ให้กำลังใจ, การออม, กิจกรรม, ความห่วงใย, การเฉลิมฉลอง
- ต้องรักษาสมดุลระหว่างเจ้าหน้าที่สหกรณ์กับสมาชิกสหกรณ์

## Review Method
หลังจัดทำรายการ 40 เฟรม:
1. ตรวจ caption duplicate
2. ตรวจ semantic / intent overlap
3. ตรวจ pose silhouette overlap
4. ตรวจ facial-expression overlap
5. ตรวจ prop repetition
6. ตรวจ usage coverage ของกลุ่มเป้าหมายทั้งสอง
7. สรุปเฟรม KEEP / REWORK / REPLACE
8. แก้ไขแล้ว QC ซ้ำจนไม่มี blocking issue
9. จึงล็อกเป็น FULL-STICKER-PRODUCTION-TABLE-v1.0

## Production Gate
ห้ามเริ่ม Full Production 40 stickers ก่อน Content QC ผ่านและ Product Owner อนุมัติรายการสุดท้าย

Hero stickers สามารถใช้เป็น visual calibration ได้ แต่ไม่ถือว่าแทน Content QC ของทั้งชุด
