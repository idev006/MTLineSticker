# SET-009 PRODUCT SSOT v1.0

## Product
- Thai name: **สหกรณ์ออมทรัพย์ตำรวจภูธรภาค 6 หมายเลข 1**
- Repository code: `SET-009-PPR6-SAVINGS-COOP-01`
- Primary channel: LINE Sticker
- Primary use: กิจกรรมสหกรณ์ การสื่อสารกับสมาชิก ประชาสัมพันธ์ และสร้างการจดจำองค์กร

## Primary Audience
กลุ่มเป้าหมายหลักของชุดนี้มี 2 กลุ่มที่ต้องออกแบบให้ใช้งานร่วมกันได้จริง:
1. **เจ้าหน้าที่สหกรณ์** — ใช้สื่อสารกับสมาชิก ให้บริการ ตอบรับ แจ้งสถานะ ประชาสัมพันธ์กิจกรรม และสร้างความสัมพันธ์ที่เป็นมิตร
2. **สมาชิกสหกรณ์** — ใช้สื่อสารในชีวิตประจำวัน ภายในกลุ่ม LINE/กิจกรรมของสหกรณ์ ตลอดจนใช้ส่งกำลังใจ ขอบคุณ รับทราบ และสื่อเรื่องการออม

### Audience design implication
- ภาษาไทยต้องสุภาพ เป็นธรรมชาติ และไม่เป็นภาษาราชการแข็งเกินไป
- ต้องมีข้อความที่เจ้าหน้าที่ใช้ตอบสมาชิกได้ทันที เช่น รับทราบครับ/ค่ะ, ยินดีให้บริการ, กำลังตรวจสอบให้, ขอบคุณครับ/ค่ะ
- ต้องมีข้อความที่สมาชิกใช้ได้เองจำนวนมาก ไม่ควรทำให้ทั้งชุดดูเหมือนสื่อประชาสัมพันธ์ทางเดียวจากองค์กร
- หลีกเลี่ยงศัพท์ภายในหรือข้อความเฉพาะงานที่สมาชิกทั่วไปไม่เข้าใจ
- น้ำเสียงรวม: เป็นมิตร อบอุ่น เชื่อถือได้ สุภาพ และใช้งานได้บ่อย

## Strategic Objective
สร้างชุดสติ๊กเกอร์ที่สมาชิกและเจ้าหน้าที่หยิบใช้ได้จริงในชีวิตประจำวัน พร้อมทำหน้าที่เป็นระบบมาสคอตขององค์กรที่ต่อยอดไปสู่ตุ๊กตา พวงกุญแจ แก้วน้ำ กระบอกน้ำ กระเป๋า เข็มกลัด สติ๊กเกอร์ไดคัท และสื่อกิจกรรมต่าง ๆ ได้

## Core Character
มาสคอต **ไก่ชนเหลืองหางขาว** ตาม Character Sheet ที่เจ้าของงานยืนยัน

### Core visual locks
- ตัวสีเหลืองทอง
- หงอนสีแดง
- หางขาวเด่น
- ดวงตากลมใหญ่ เป็นมิตร
- แก้มอมชมพู
- รูปร่างอวบแน่น น่ากอด
- เสื้อฮู้ดสีฟ้าเป็น signature look หลัก
- `สอ.ภ.6` เป็น identifier บนเสื้อเมื่อพื้นที่และความชัดเจนเอื้ออำนวย

## Brand Personality
- เป็นมิตร
- จริงใจ
- พึ่งพาได้
- ขยันและตื่นตัว
- อบอุ่นแบบครอบครัว
- มั่นคงแต่ไม่เคร่งขรึม
- สุภาพแต่มีชีวิตชีวา

## Communication Pillars
1. **Everyday Utility** — สวัสดี ขอบคุณ รับทราบ ได้เลย ดูแลตัวเอง พักผ่อน
2. **Cooperative Service** — ยินดีให้บริการ ติดต่อได้เลย ดำเนินการให้ ตรวจสอบให้
3. **Savings & Financial Wellbeing** — ออมก่อน ใช้ทีหลัง มีเงินมีความสุข ออมวันนี้เพื่อวันหน้า
4. **Activity & Community** — เจอกันที่กิจกรรม สู้ ๆ ร่วมมือกัน ยินดีด้วย
5. **Warm Relationship** — ห่วงใย กำลังใจ สุขสันต์วันสำคัญ

## Design Principle
สติ๊กเกอร์ต้องอ่านอารมณ์ได้ในเวลาสั้น แม้ย่อเล็กบนหน้าจอมือถือ โดย silhouette, pose, face และ prop ต้องช่วยกันสื่อ intent; หลีกเลี่ยงการพึ่งข้อความอย่างเดียว

## Merchandise Compatibility
ทุก pose หลักควรผ่านคำถาม 4 ข้อ:
1. ทำเป็นตุ๊กตา 3 มิติได้หรือไม่
2. ตัดเป็นพวงกุญแจ/สติ๊กเกอร์ไดคัทแล้ว silhouette ยังชัดหรือไม่
3. พิมพ์บนแก้วหรือกระเป๋าโดยลดรายละเอียดแล้วยังจำตัวละครได้หรือไม่
4. ไม่มีชิ้นส่วนเล็ก/เส้นบางที่ทำให้ผลิตจริงยากเกินไปหรือไม่

## Production Target
- 40 stickers
- Hero review ก่อน Full Production
- ลดคำและท่าที่ซ้ำหรือใกล้เคียงกัน
- อย่างน้อย 70% ของชุดควรใช้ได้บ่อยโดยไม่ผูกกับกิจกรรมเฉพาะครั้ง
- 20–30% ใช้สื่อสารด้านสหกรณ์/การออม/กิจกรรม
- ไม่เกิน 10% เป็น seasonal หรือ ceremonial content ในชุดแรก
- ต้องมี balance ระหว่างข้อความฝั่ง **เจ้าหน้าที่ → สมาชิก** และ **สมาชิก ↔ สมาชิก/เจ้าหน้าที่**

## Success Criteria
- เห็นภาพแล้วรู้ว่าเป็นมาสคอตเดียวกันทุกเฟรม
- มี signature look ที่จำได้แม้ไม่มีข้อความ
- ใช้งานจริงในกลุ่ม LINE ของสหกรณ์ได้บ่อย
- เจ้าหน้าที่และสมาชิกต่างมีอย่างน้อย 10–15 เฟรมที่หยิบใช้ได้บ่อย
- สามารถนำอย่างน้อย 10 pose ไปผลิต merchandise ได้โดยแทบไม่ต้อง redesign
