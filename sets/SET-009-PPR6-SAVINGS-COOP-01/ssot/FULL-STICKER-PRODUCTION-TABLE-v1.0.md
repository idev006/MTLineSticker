## Cross-set Visual Rules
- Hero visual calibration ใช้เฟรม 01, 02, 03, 11, 17, 26 เป็น reference หลัก
- เสื้อฮู้ดสีฟ้าเป็นลุคหลัก; โปโล/ชุดกิจกรรม/เครื่องแบบตำรวจใช้เพื่อแยกบริบท ไม่ให้ทุกเฟรมเหมือนกัน
- ห้ามใช้ thumbs-up ซ้ำเป็น gesture หลักมากกว่า 2 เฟรม และห้ามใช้พนมมือซ้ำหลาย intent
- พร็อพต้องช่วยสื่อความหมาย ไม่ใช้พร็อพเพื่อเติมพื้นที่เฉย ๆ
- ทุกเฟรมต้องอ่าน intent ได้แม้ลดขนาดและมองก่อนอ่านข้อความ
- Sticker sheet production ต้องยึด `PRODUCTION-SPEC-v1.0.md`: PNG transparent, frame 512×512 px, margin/padding 20 px, frame border ~3 px, white backing ทึบ 100% ไม่มีรูหรือช่องโปร่งใสภายใน และมีขอบสีขาวสำหรับไดคัท
