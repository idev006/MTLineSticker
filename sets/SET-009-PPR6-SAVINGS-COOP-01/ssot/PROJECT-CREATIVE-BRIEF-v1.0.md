# PROJECT CREATIVE BRIEF v1.0

## โครงการ
LINE Sticker: **สหกรณ์ออมทรัพย์ตำรวจภูธรภาค 6 หมายเลข 1**

## กลุ่มผู้ใช้หลัก
- สมาชิกสหกรณ์
- เจ้าหน้าที่สหกรณ์
- ข้าราชการตำรวจและครอบครัว
- ผู้ร่วมกิจกรรมของสหกรณ์

## โจทย์การสื่อสาร
ทำให้การสื่อสารเรื่องงานบริการ การออม กิจกรรม และความสัมพันธ์ในองค์กรดูเป็นมิตรขึ้น โดยใช้มาสคอตที่มีอัตลักษณ์เฉพาะของสหกรณ์และสามารถเติบโตเป็น character brand ระยะยาว

## Big Idea
**“เพื่อนคู่ใจของครอบครัวตำรวจ ออมไปด้วยกัน ก้าวไปได้ไกลกว่า”**

## Visual Direction
- Soft, friendly, clean, cheerful
- พื้นฐานสีฟ้าอ่อน/ฟ้าสหกรณ์ + เหลืองทองของตัวไก่ + ขาวของหาง
- รูปทรงกลมมน อ่านง่ายในขนาดเล็ก
- อารมณ์ชัดเจนกว่ารายละเอียดเครื่องแต่งกาย
- เสื้อฮู้ดฟ้าเป็น signature outfit หลักของชุดที่ 1
- เครื่องแบบตำรวจใช้เฉพาะเฟรมที่มีเหตุผลด้านบริบท ไม่ใช้เป็น default ทุกเฟรม

## Tone of Voice
สุภาพ เป็นกันเอง กระชับ อบอุ่น ใช้ภาษาไทยร่วมสมัย อ่านเร็วในแชต และหลีกเลี่ยงภาษาราชการยาว ๆ

## Sticker Content Mix
- 16–18 เฟรม: everyday communication
- 8–10 เฟรม: cooperative service/workflow
- 5–7 เฟรม: savings/financial wellbeing
- 4–6 เฟรม: encouragement/community/activity
- 2–4 เฟรม: warm/celebratory/seasonal

## Pose Strategy
ห้ามให้หลายเฟรมต่างกันเพียงข้อความ ต้องออกแบบ pose family ให้แตกต่างจริง เช่น ไหว้, thumbs-up, saluting, running, hugging heart, holding passbook, holding piggy bank, checking document, cheering, resting, celebrating, pointing, presenting, calling, carrying gift

## Hero Set Recommendation
สร้าง Hero 8–12 เฟรมก่อน โดยครอบคลุม:
- ทักทาย
- ขอบคุณ
- รับทราบ
- ยินดีให้บริการ
- ออมก่อน ใช้ทีหลัง
- สู้ ๆ
- ดูแลกันนะ
- ยินดีด้วย
- กำลังดำเนินการ
- ติดต่อได้เลย

Hero ต้องทดสอบ 4 เรื่อง: character fidelity, pose readability, text hierarchy, merchandise silhouette

## Marketing / Activity Use
สามารถนำ Hero poses ไปใช้ใน:
- ป้ายกิจกรรม
- booth/event backdrop
- LINE OA / social media
- ของรางวัลและของชำร่วย
- เสื้อ/กระเป๋า/แก้ว/พวงกุญแจ
- สื่อรณรงค์การออม

## Constraints
- ไม่ทำ character ให้ผอม ยาว หรือสัดส่วนเปลี่ยนจาก Character Sheet
- ไม่เพิ่มรายละเอียดเครื่องแบบที่รบกวนความน่ารักหรืออ่านยาก
- ไม่ใช้ prop มากเกินไปในหนึ่งเฟรม
- ไม่ใช้ข้อความยาวจนตัวละครเล็กลงมาก
- ต้องมี safe area รอบตัวละครและข้อความสำหรับการ crop/export
