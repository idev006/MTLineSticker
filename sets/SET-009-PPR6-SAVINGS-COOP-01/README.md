# SET-009 — สหกรณ์ออมทรัพย์ตำรวจภูธรภาค 6 หมายเลข 1

ชื่อชุด: **สหกรณ์ออมทรัพย์ตำรวจภูธรภาค 6 หมายเลข 1**  
รหัสชุดใน repo: `SET-009-PPR6-SAVINGS-COOP-01`  
ประเภท: LINE Sticker / Cooperative Activity Mascot  
สถานะ: **PLANNING / CHARACTER VISUAL LOCKED FROM OWNER REFERENCE**

## เป้าหมาย
พัฒนาชุดสติ๊กเกอร์ LINE สำหรับใช้ในกิจกรรม การประชาสัมพันธ์ และการสื่อสารของสหกรณ์ออมทรัพย์ตำรวจภูธรภาค 6 โดยให้มีความเป็นมิตร จดจำง่าย ใช้งานจริงได้บ่อย และสามารถต่อยอดมาสคอตไปสู่ของชำร่วยและสื่อประชาสัมพันธ์ได้

## Character Direction
- มาสคอตหลัก: **ไก่ชนเหลืองหางขาว**
- บุคลิก: ร่าเริง เป็นมิตร ขยัน ตื่นตัว ซื่อสัตย์ อบอุ่น พึ่งพาได้
- รูปร่าง: อวบแน่น นุ่ม น่ากอด แขนขาสั้นป้อม แต่ยังดูคล่องแคล่ว
- Character Sheet: ใช้ภาพที่เจ้าของงานส่งและอนุมัติในบทสนทนาปัจจุบันเป็น Visual SSOT
- ชุดหลัก: เสื้อฮู้ดสีฟ้า มีเครื่องหมาย/ข้อความ `สอ.ภ.6`
- ชุดรอง: เสื้อโปโลสหกรณ์, ชุดกิจกรรม/กีฬา, เครื่องแบบตำรวจ simplified สำหรับบางสถานการณ์
- สีหลัก: เหลืองทอง, ขาว, ฟ้าอ่อน, กรมท่า, แดง, ชมพูอ่อน
