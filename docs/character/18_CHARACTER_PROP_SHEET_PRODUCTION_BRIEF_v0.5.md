# Character + Prop Sheet Production Brief v0.5

## Objective
Create a single-source visual reference for พี่พร้อม: Paper-Tear Mascot so all later sticker images reproduce the same character, materials and props.

## Deliverable A — Character Master Sheet
Must include:
1. hero pose
2. five-view turnaround: front, 3/4 front, side, 3/4 rear, back
3. head construction and proportion callouts
4. silhouette study
5. 12 expressions
6. 8 workflow gestures
7. tiny-size readability previews

### Required expressions
neutral/deadpan, polite, acknowledge, focused, pleased, confused, worried, urgent, work-overload, tired, request/help, dry humor.

### Required gestures
acknowledge/salute, invite, request data, coordinate by phone, type/work, follow up, urgent rush, short break.

## Deliverable B — Prop Sheet
Lock shape, scale, construction and material rules for:
- READY Folder (hero prop)
- document stack
- smartphone
- laptop/notebook computer
- pen
- sticky note
- coffee cup
- paper clips / binder clips / masking tape

For each prop show front/side or functional views where useful, scale against character, dominant material, recurring torn-edge language and details that must not change.

## Deliverable C — Material / Texture Guide
Show approved samples for:
- skin/kraft paper
- black hair/brow paper
- brown uniform paper
- mustard accent paper
- crumpled paper
- torn fibers
- masking tape
- metal clips
- collage shadow depth

## Visual rules
- physical collage feeling, deliberately rough but controlled
- large readable shapes before small texture
- irregular torn edges visible in every major body region
- limited warm palette
- no vector-perfect silhouettes
- no photorealistic face
- no dependency on actual police insignia for recognition

## Review gates
A sheet is not approved unless:
1. all five views clearly depict the same person
2. face identity survives removal of uniform and props
3. silhouette is distinguishable from generic chibi characters
4. READY Folder is consistent across views
5. paper-tear construction is coherent rather than decorative
6. character remains readable at sticker/thumbnail scale

## Production sequence
Character Master → Prop Sheet → Material Guide → recognition review → 6–8 prototype stickers → correction pass → only then consider full Set 01 production.
