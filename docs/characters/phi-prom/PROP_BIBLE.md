# Phi Prom Prop Bible

## Hero prop: READY folder
Warm yellow/brown paperboard, visible torn edges, readable READY label, optional clip/tape detail, stable shape and scale.

## Supporting props
Document stacks, laptop, smartphone, pen, notes, coffee cup, clips, tape, clocks/hourglasses when relevant.

Props must reinforce the caption's workflow intent and never overwhelm the character at chat size.
