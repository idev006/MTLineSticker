# Pose Library

Canonical workflow gestures:
- Salute / acknowledge
- Invite / open hand
- Request information
- Coordinate by phone
- Work at laptop
- Review documents
- Follow up / point to time
- Urgent movement
- Present completed work
- Rest / coffee
- Wai / thanks or apology
- Deadpan refusal/comedy

A pose should communicate the intent before the caption is read.
