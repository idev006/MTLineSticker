# Product & Market Strategy

## 1. Category Positioning
Not “cute police stickers.”

Position as:
**Work-language stickers designed from the real workflow of administrative police personnel.**

## 2. Competitive Advantage
The moat is customer insight, not illustration complexity.

Competitors can imitate style. They are less likely to imitate a deeply researched activity-to-caption system, relationship-aware tone system, and consistent workplace character IP.

## 3. Value Proposition
### Functional
Use instead of typing repeated work phrases.

### Emotional
Make daily work communication feel warmer and more human.

### Identity
“This is our work life.”

## 4. Product Principles
1. Workflow first, caption second, illustration third.
2. One sticker = one communication intent.
3. Utility before novelty.
4. Humor must be peer-safe and duty-safe.
5. Character must remain readable at small chat size.
6. Avoid unnecessary real-world insignia and protected identities.
7. Every set must have a distinct usage territory.

## 5. Portfolio Architecture
### Set 01 — Everyday Admin Work
Broad daily-use entry product.

### Set 02 — Meetings & Coordination
Invitation, scheduling, meeting preparation, meeting status, summary, coordination.

### Set 03 — Follow-up & Deadlines
Progress chasing, reminders, urgency, due dates, late inputs.

### Set 04 — Documents & Reporting
Documents, corrections, proposal, signature, approval, reporting, distribution.

### Set 05 — Admin Work Life / Humor
Workload, coffee, fatigue, interruptions, end-of-day humor.

## 6. Set 01 Content Allocation
Target distribution:
- 22 Core workflow utility
- 8 coordination/meeting/follow-up
- 5 urgency/status
- 5 human/humor

Allocation is a guide, not a hard quota; final selection should be based on usage value and validation.

## 7. Brand Tone
Professional × Friendly × Inside Humor

Humor rule:
**Laugh with the work life, never at citizens, public service, colleagues, or superiors.**

## 8. Character Positioning
Competent + Busy + Friendly + Relatable

Avoid:
- childish/baby-like treatment
- hyper-macho hero styling
- incompetence/laziness as the central joke
- cynical anti-work messaging
- excessive rank signaling

## 9. Organic Growth Model
Target user buys → sends in work group → peers see sticker → recognition/humor generates curiosity → peers inspect/buy → repeat.

Therefore the product should optimize for **sendability**, not only visual appeal.

## 10. Pricing/Packaging Principle
Use standard LINE market pricing available at launch. Do not compete primarily through discounting. Product differentiation should come from relevance, identity, and usage frequency.
