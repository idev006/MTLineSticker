# Naming Convention

Sets: SET-###-SHORT-NAME  
Stickers: SET###-STK###  
Character assets: CHR-PHIPROM-<TYPE>-###  
Set assets: SET001-STK001_<stage>.<ext>

Stages: source, candidate, approved, export.

Prefer ASCII production filenames. IDs are immutable after approval and must never be reused for a different semantic asset.
