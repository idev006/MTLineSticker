# Visual Style Guide

## Scope
This repository contains multiple character IPs. Global visual rules must remain character-neutral; character-specific materials, proportions, costume, hair, and rendering rules belong in each character/set SSOT.

## Communication priority
For every sticker:
**message + expression + gesture + caption > decorative detail**.

A visually beautiful candidate that is slow to understand in chat is not acceptable.

## Global readability rules
- face/expression must survive thumbnail reduction
- gesture/action must read quickly
- caption must remain large and legible
- props must reinforce the message and not overwhelm the character
- avoid scene-like backgrounds unless the set explicitly requires them
- avoid tiny full-body characters when they weaken expression readability
- effects must not create ambiguous foreground edges

## Character fidelity
When an approved Character Sheet exists, preserve its locked identity. Do not silently convert an adult semi-anime character into chibi, alter the haircut, face proportions, signature wardrobe, or other locked traits for stylistic convenience.

## Background and cutout
Candidate backgrounds must be removable when used. Final LINE sticker assets require transparent PNG according to current platform rules.

## Typography
Thai typography must be proofread and readable at chat size. AI-generated text is never accepted as final without deterministic spelling verification.
