# Visual Style Guide

Torn-paper collage mascot with visible irregular fibers and layered paper construction.

Priority: face + gesture + caption > costume micro-detail.

Candidate backgrounds must be flat and strongly separated from all foreground elements for clean removal.

Thai typography must remain large and clear at chat size. Effects should be restrained and must not create ambiguous foreground edges.

Hair, brows, material language, uniform simplification and prop scale must remain consistent across sets.
