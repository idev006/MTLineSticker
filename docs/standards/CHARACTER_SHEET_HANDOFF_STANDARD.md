# Character Sheet Handoff Standard — MTLineSticker

A Character Sheet handoff is complete only when the user receives current Character source documents, current `REFERENCE_INDEX.md`, only references appropriate to Character Sheet generation, runtime handoff summary, copy-paste runtime prompt and a simple README. When archive creation is available, create `CHARACTER_SHEET_HANDOFF.zip`.

Reference lists are generated dynamically by role/authority from REFERENCE_INDEX; never hard-code a numeric count. Identity, style, wardrobe, accessory and pose references may coexist.

Owner decisions already requested must be applied back to the current package before continuing. Package manifests distinguish payload count from total archive entries and state self-hash omission explicitly. Shared Character rules use stable global lock IDs instead of duplicated long text.
