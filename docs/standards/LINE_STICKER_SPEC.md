# LINE Sticker Technical Standard

Working project standard; verify the latest official LINE Creators Market rules immediately before submission.

- Set 001 target: 40 stickers
- Final stickers: PNG, transparent background
- Sticker reference maximum: 370 × 320 px
- Main image reference: 240 × 240 px
- Chat tab reference: 96 × 74 px

## AI candidate sheets
If transparency is unreliable, use one flat high-contrast background distinct from all sticker elements, avoid gradients/background shadows, then remove it before final export.

## Batch source grid
The project may use 5×2 sheets of ten 512×512 working frames, 20 px internal padding, and 20 px spacing/margins when a set brief specifies it.
