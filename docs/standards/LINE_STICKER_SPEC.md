# LINE Sticker Technical Standard

Working project standard. Verify the latest official LINE Creators Market rules immediately before submission; official platform rules override this document if they change.

## Static sticker requirements — current working baseline
- Allowed set quantities: 8, 16, 24, 32, or 40 sticker images
- Sticker image maximum: 370 × 320 px
- Main image: 240 × 240 px
- Chat thumbnail icon: 96 × 74 px
- PNG format
- Transparent background required
- RGB color mode
- At least 72 dpi
- Even-numbered width and height
- Each sticker image: 1 MB or less
- ZIP package: 60 MB or less when submitted as one ZIP
- Recommended trimmed-image margin: around 10 px, balanced around the artwork

## Product principle
A sticker is a communication asset, not a standalone illustration. Apply `docs/standards/STICKER_COMMUNICATION_STANDARD.md` before visual production.

LINE's recommended direction is easy-to-use daily communication with expressions, messages, and illustrations that are immediately understandable. Avoid compositions with poor visibility, excessive scene detail, or tiny full-body characters that become unreadable in chat.

## AI candidate sheets
If transparency is unreliable during candidate generation, use one flat high-contrast removable background distinct from all sticker elements, with no gradients/background shadows, then remove it before final export. Final deliverables must have real alpha transparency.

## Batch source grid
The project may use 5×2 sheets of ten 512×512 working frames, 20 px internal safe padding, and exact deterministic assembly when a set brief specifies it. Review-sheet borders/frame numbers are QA aids only and must not appear in final individual sticker assets.

## Pre-submission verification
Re-check the official LINE Creators Market sticker guideline on submission day, especially dimensions, file size, transparency, text/review restrictions, and current review policy.
