# QA Standard

## Content
Correct IDs; approved caption; Thai spelling reviewed; correct intent and tone.

## Character
Same Phi Prom identity; correct torn-paper construction; approved signature cues; pose supports caption.

## Visual
Readable caption; no clipping; clean removable background in candidates; clean silhouette after removal.

## Technical
Correct dimensions; PNG; transparent final background; naming and manifest correct; submission package complete.

A set cannot become APPROVED while any blocking QA item fails.
