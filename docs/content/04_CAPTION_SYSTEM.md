# Set 01 Caption System — Police Admin / Everyday Work

Status: Content Candidate v0.9 — reviewed, not yet final production lock.

## Review principles
Each caption must justify its slot by at least one of these roles:
1. High-frequency work utility
2. Workflow status / coordination
3. Meeting / follow-up / deadline utility
4. Human-relatable or signature humor

Selection criteria: frequency, breadth, work relevance, clarity at sticker size, emotional value, brand distinctiveness, and safety.

## Portfolio balance
- Core utility / status: 1–15, 28–33
- Follow-up / meeting / document workflow: 16–27
- Urgency: 34–36
- Human / humor / brand memory: 37–40

## Design implications
- Captions 34–36 should be designed as one visual escalation trilogy: ด่วน → ด่วนมาก → ด่วนที่สุด.
- Caption 40 is a signature deadpan moment for “พี่พร้อม”; visual tone must clearly signal humor and peer-context, not refusal of duty.
- All 40 must later receive Caption × Activity × Receiver × Expression × Pose × Prop mapping before production lock.
