# QA Checklist

## A. Strategy
- [ ] Sticker maps to a real workflow or intentional human/humor moment
- [ ] Caption has one clear communication intent
- [ ] Tone matches intended recipient relationship
- [ ] Set 01 does not consume too much content reserved for future themed sets

## B. Character Consistency
- [ ] Face construction matches Character Bible
- [ ] Head/body ratio consistent
- [ ] Hairstyle/costume consistent
- [ ] Props use canonical designs
- [ ] Expression is readable at small size

## C. Caption
- [ ] Exact approved Thai wording
- [ ] No typo
- [ ] Thai diacritics render correctly
- [ ] Short enough to read quickly
- [ ] Text contrast is strong
- [ ] Text does not clash with character/props

## D. Appropriateness / Brand Safety
- [ ] No real person likeness
- [ ] No unapproved real unit marks/insignia
- [ ] No political messaging
- [ ] No violent or weapon-centered treatment
- [ ] Humor does not demean citizens, colleagues, or superiors
- [ ] No corruption/avoid-duty joke
- [ ] No implication of official endorsement unless authorized

## E. LINE Technical
- [ ] Correct sticker count: 40
- [ ] Main image 240×240
- [ ] Sticker images within 370×320 maximum
- [ ] Chat tab 96×74
- [ ] PNG exports
- [ ] Transparent/clean background treatment as applicable
- [ ] Margin checked
- [ ] File size/packaging checked against current official requirements
- [ ] Official current guidelines re-checked before submission

## F. Final Package
- [ ] `SET01-STK-001` to `040` complete
- [ ] Main image complete
- [ ] Chat tab complete
- [ ] Product title approved
- [ ] Description approved
- [ ] Copyright field approved
- [ ] Submission metadata stored in repo
