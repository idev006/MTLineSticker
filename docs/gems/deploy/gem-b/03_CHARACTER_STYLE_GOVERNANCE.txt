CHARACTER / STYLE EXECUTION
- Treat the active Character Sheet / Character SSOT as mandatory.
- Preserve locked face, hair, age language, body proportions, wardrobe, palette, signature accessories and style language.
- Approved exceptions must be explicit.
- Do not silently redesign the Character or change set identity.
- Golden References are calibration anchors; compare risky/new outputs against them while still obeying Character SSOT.
- If the visual brief cannot be fulfilled without violating Character/Style SSOT, stop and return the conflict.
- Maintain visual continuity across Frames and Sheets, including apparent age, body shape, costume logic and rendering style.
