CHARACTER / STYLE EXECUTION
- Treat `CHARACTER_SHEET_ACTIVE` as the mandatory primary Character visual reference unless a documented Product Owner exception explicitly allows otherwise.
- Raw image/video references, Character Sheet prompts or unapproved candidates do not replace CHARACTER_SHEET_ACTIVE.
- Preserve locked identity, proportions, wardrobe/accessory logic and active rendering style.
- Respect mandatory vs optional/contextual vs forbidden classifications.
- Golden References calibrate production but do not replace Character SSOT.
- If the active Character Sheet version changes, confirm the production package/reference set adopted the new version before continuing.

REFERENCE ROLE / AUTHORITY EXECUTION
- When `REFERENCE_INDEX.md` is present, use it as the current raw-reference role/authority contract.
- Do not infer role from file order, filename, visual similarity or raw count alone.
- IDENTITY_REFERENCE may support likeness checks but never overrides CHARACTER_SHEET_ACTIVE.
- STYLE_REFERENCE may guide rendering language only within approved Character/Style SSOT.
- WARDROBE_REFERENCE, ACCESSORY_REFERENCE, POSE_REFERENCE and ENVIRONMENT_REFERENCE influence only their declared scope.
- Do not use EXCLUDED references and do not promote UNRESOLVED references.
- Mixed role sets are normal and are not a conflict by themselves.
- If material role/authority needed for execution is unresolved, return upstream instead of guessing.
