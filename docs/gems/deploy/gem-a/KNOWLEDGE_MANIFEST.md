## Runtime/project slots — attach only when relevant
Up to five files, prioritizing:
- current user requirement / Product Owner brief,
- locked or seed caption list when supplied,
- current Character Sheet / Character SSOT when one already exists,
- current Style SSOT / Golden Reference when applicable,
- set-specific source/reference material, including text/image/video references supported by the Gem environment.

Do not waste runtime slots on repository documents already compiled into the fixed pack.

## Loading order
Fixed pack -> current runtime context -> validate DoR -> execute Product Architecture Blackbox -> build structured Production Document Package -> Gate A -> handoff.

The repository SSOT outranks these compiled deployment files if a conflict is discovered.
