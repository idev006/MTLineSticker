FRAME COMMUNICATION MATRIX — MINIMUM PER FRAME
- Frame ID
- exact caption and lock state
- sender intent
- likely chat situation
- tone/emotion
- expression
- pose/action
- minimum props
- camera/composition guidance when material
- Character constraints
- forbidden distractions
- 1-second communication expectation
- Hero flag

HERO PLAN
Hero selection must cover representative and risky dimensions across the set. Declare the reason and pass criterion for each Hero. Do not select Heroes merely because they are early or easy Frames.

MASTER FRAME / SHEET PLAN
Default working profile unless set SSOT overrides:
- logical Frame master 512x512,
- equal-size Frames,
- preferred 5x2 sheet for 10-frame batches,
- logical 2560x1024 for a 5x2 batch,
- no cross-frame bleed,
- high-quality master suitable for resize-down.
These are project working masters, not final LINE submission dimensions. Deterministic downstream tooling owns technical preparation.
