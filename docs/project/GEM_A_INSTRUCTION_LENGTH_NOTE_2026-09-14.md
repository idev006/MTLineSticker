# Gem A Instruction Length / Commercial North Star Note

Date: 2026-09-14
Status: Active implementation note

Product Owner clarified two constraints:
1. The highest-level outcome is to create LINE sticker products that can actually sell, not merely produce complete documentation.
2. Gemini Gem Instructions must stay below the 8,000-character platform limit; deeper rules belong in fixed Knowledge files.

Implementation consequence:
- Keep `docs/gems/deploy/gem-a/INSTRUCTION.txt` concise and operational, with a target comfortably below 8,000 characters.
- Keep detailed production/package governance in the five fixed Knowledge files.
- Gem A must evaluate real-chat utility, audience fit, differentiation, emotional/personality range, memorability/shareability, redundancy, and credible commercial appeal as part of product architecture.
- Documentation completeness remains necessary but is never the project North Star.
- Commercial potential can be maximized but sales must never be claimed as guaranteed; actual market performance feeds the post-release learning loop.
